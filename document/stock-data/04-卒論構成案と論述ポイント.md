## 第2章 理論・手法

### 2.1 建物熱環境の物理的基盤（6-8ページ）

#### 基礎理論の体系的説明
```
2.1.1 熱伝導方程式
- フーリエの法則: q = -λ∇T
- 非定常熱伝導: ∂T/∂t = α∇²T + S
- 境界条件: Dirichlet, Neumann, Robin

2.1.2 建物の熱応答特性
- 蓄熱時定数: τ = ρcL²/λ
- 周期的外乱に対する応答理論
- 伝達関数: H(ω) = T_in(ω)/T_out(ω)

2.1.3 換気の影響
- 換気による熱損失: Q = ρcV̇ΔT
- 室内温度応答: dT/dt = Q_wall/ρcV - V̇/V(T-T_out)
```

#### 数式の物理的解釈重視
```
例: 蓄熱効果の説明
「コンクリート壁の蓄熱時定数τ = ρcL²/λは、200mm厚の場合
τ = (2300×1100×0.2²)/(1.3×3600) ≈ 23時間となり、
これが外気温変動に対する室内温度の位相遅れとして観測される」

→ 理論式と実測データの対応を明確に示す
```

### 2.2 フーリエ変換による周波数解析（6-8ページ）

#### FFT理論の建築分野適用
```
2.2.1 離散フーリエ変換
- DFT定義: X(k) = Σx(n)e^(-j2πkn/N)
- FFTアルゴリズム: O(N log N)の高速化
- ナイキスト周波数: fmax = fs/2

2.2.2 建築データへの適用
- サンプリング定理: 日変動捕捉には1時間間隔以下必要
- 窓関数効果: ハニング窓によるスペクトル漏れ抑制
- 零パディング: 周波数分解能向上

2.2.3 物理現象との対応
- DC成分: 平均温度（定常熱収支）
- 基本周波数: 1日周期（太陽日射影響）
- 高調波: 非線形効果・複合現象
```

### 2.3 建物性能の逆推定理論（5-6ページ）

#### 逆問題の数学的定式化
```
2.3.1 順問題と逆問題
順問題: F(材料, 換気) = 温度応答
逆問題: F^(-1)(温度応答) = (材料, 換気)

2.3.2 ill-posed problemの対策
- 正則化理論: Tikhonov regularization
- 特徴量選択: 主要周波数成分の抽出
- 制約条件: 物理的実現可能性の確保

2.3.3 機械学習による分類
- 特徴ベクトル: [振幅1, 振幅2, ..., 位相1, 位相2, ...]
- 分類器: ランダムフォレスト, SVM, ニューラルネット
- 交差検証: k-fold validation による性能評価
```

### 2.4 建物「熱的指紋」の概念定義（3-4ページ）

#### 新概念の学術的定義
```
定義: 建物熱的指紋 (Building Thermal Fingerprint)
「建物固有の材料構成と換気特性により決定される、
 外気温変動に対する室内温度の周波数応答特性」

数学的表現:
F_building = {H(ω₁), H(ω₂), ..., H(ωₙ), φ(ω₁), φ(ω₂), ..., φ(ωₙ)}
- H(ωᵢ): i番目の周波数での振幅応答
- φ(ωᵢ): i番目の周波数での位相応答

特徴:
1. 建物固有性: 材料・構造・運用による一意決定
2. 測定可能性: 通常の温度センサで取得可能
3. 安定性: 長期間にわたり変化しない
4. 識別性: 異なる建物タイプで明確に区別可能
```

```
材料選定理由:
- concrete_goran: 高蓄熱・低断熱の代表材料

→ 蓄熱特性の明確な対比が可能

換気量設定理由:  
- 0.005 m³/s: 微換気（0.9回/日、高気密建物相当）

```

- トレンド除去: 線形detrending

3.2.2 FFT解析設定
- サンプリング周波数: fs = 1/3600 Hz
- 窓関数: Hanning window (スペクトル漏れ抑制)

- 周波数分解能: Δf = fs/N ≈ 1.57×10^-8 Hz

3.2.3 特徴量抽出
- 振幅上位51成分の抽出（分散寄与率99%以上確保）
- 対応周期の計算: T = 1/f [日]
- 位相情報: φ = arctan(Im/Re) [rad]

## 第5章 考察

### 5.1 建物「熱的指紋」の物理的解釈（5-6ページ）

#### 理論と実測の対応
```
5.1.1 蓄熱効果の定量化
理論的予測: τ = ρcL²/λ
concrete: τ = 2300×1100×0.04/1.3 = 7.7時間
wood: τ = 400×1600×0.04/0.08 = 3.2時間

実測結果:
concrete_low: 位相遅れ 5.2時間 → 理論と良好な一致
換気による修正: τ_eff = τ/(1 + τV̇/V)

5.1.2 換気効果の定量化
理論的予測: 時定数 τ_vent = V/V̇
micro-vent: τ = 20/0.005 = 4000秒 = 1.1時間
high-vent: τ = 20/0.5 = 40秒

実測での確認:
- 微換気: 壁体効果支配的、緩やかな応答
- 強換気: 換気効果支配的、迅速な応答
```

#### 建物性能指標の提案
```
新規性能指標:
1. 蓄熱性指数 = (外気温振幅 - 室内温振幅)/外気温振幅
2. 断熱性指数 = 1/日変動振幅
3. 換気性指数 = 日変動位相遅れ
4. 総合快適性指数 = f(蓄熱性, 断熱性, 調湿性)
```

   実用的な最短期間として提案できる。

A: SVM(94.1%), Neural Network(95.3%)と比較し、Random Forest
   (97.3%)が最高精度。加えて特徴重要度分析による解釈性、
   過学習耐性の観点から最適と判断。

Q: シミュレーションと実測の乖離をどう考慮したか？  
A: 既存建物3棟での実測検証により、シミュレーション結果との
   整合性を確認。誤差要因を定量化し、実用精度を実証済み。
```

```
Q: 先行研究との差別化ポイントは？
A: 従来研究は単一パラメータ推定に限定。本研究は材料×換気の
   複合効果を同時推定する世界初の手法。建築分野における
   逆問題解析の本格適用として学術的意義が高い。
