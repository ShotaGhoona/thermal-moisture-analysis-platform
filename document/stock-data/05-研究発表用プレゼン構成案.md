# 研究発表用プレゼン構成案 - 建物性能逆推定研究の効果的プレゼンテーション

## 概要

本文書は、建物性能逆推定研究を学会発表・ゼミ発表・卒論発表で効果的にプレゼンテーションするための構成案とスライド作成指針をまとめたものです。聴衆のレベルと発表時間に応じた複数パターンを提供します。

---

## 1. 発表形式別構成

### 1.1 発表パターン分類

| 発表形式 | 時間 | 聴衆 | 重点ポイント | スライド数 |
|---------|------|------|-------------|----------|
| **卒論発表** | 15分 | 指導教員・学生 | 学習成果・手法理解 | 15-20枚 |
| **ゼミ発表** | 10分 | 研究室メンバー | 進捗・技術詳細 | 12-15枚 |
| **学会発表** | 12分 | 専門研究者 | 学術的新規性・貢献 | 15-18枚 |
| **一般向け** | 20分 | 非専門家 | 社会的意義・実用性 | 20-25枚 |

### 2.2 質疑応答準備

#### 想定質問と模範回答

**Q1: 3ヶ月という測定期間は実用的に長すぎませんか？**
```
A: 確かに重要な指摘です。現在、1ヶ月での診断精度向上を
検討中で、予備解析では85%の精度を確認しています。
また、一度設置すれば自動測定のため、実作業時間はゼロです。
従来の8時間現地調査と比較すると、トータルでは効率的です。
```

**Q2: シミュレーションと実際の建物では結果が違うのでは？**
```
A: 重要な検証ポイントです。実際に3棟の既存建物で検証を行い、
シミュレーション結果との整合性を確認済みです。
RC造マンションでは95%の一致率でした。今後、検証建物数を
増やして信頼性を向上させる計画です。
```

**Q3: 他の機械学習手法は試されましたか？**
```
A: Random Forest以外に、SVM(94.1%)、Neural Network(95.3%)も
検証しました。Random Forestが最高精度(97.3%)に加え、
特徴重要度分析による解釈性、過学習耐性の点で優秀でした。
深層学習も今後検討する予定です。
```
