## 共通設定（全パターン）

### 熱伝達率
```
    位置      | alphac | alphar | 総合α
    ----------+--------+--------+-------
    外側(IP)  |  9.0   |  4.4   | 13.4  [W/m²K]
    内側(IM)  |  4.9   |  4.4   |  9.3  [W/m²K]
```

### 日射
```
    ar_IP = 0 (日射吸収なし)
    ar_IM = 0 (日射吸収なし)
```

### 材料略称
```
    GW   = glass_wool_16K (グラスウール16K)
    PB   = plasterboard (石膏ボード)
    和紙 = paper_washi
```
