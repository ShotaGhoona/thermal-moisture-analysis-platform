# 建物内温湿度環境解析 - 実行ファイル

## 概要

このディレクトリには、建物ネットワークモデル（BNM: Building Network Model）による熱水分同時移動解析の実行ファイルが格納されています。

## 実行方法

```bash
# thermal-analysis ディレクトリから
julia legacy-julia/run/main.jl

# legacy-julia ディレクトリから
julia run/main.jl
```

## 計算の物理的背景

### 解析対象

建物内の温湿度環境を、以下の4要素のネットワークとしてモデル化：

```
┌─────────────────────────────────────────────────────────────┐
│                    BNM (Building Network Model)              │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│    ┌──────────┐         壁体          ┌──────────┐         │
│    │  外気    │ ←─────────────────→ │   室内   │         │
│    │ (Climate)│    熱流 q [W/m²]      │  (Room)  │         │
│    │          │    水蒸気流 jv        │          │         │
│    └────┬─────┘    液水流 jl          └────┬─────┘         │
│         │                                   │              │
│         └───────────── 換気 ─────────────────┘              │
│              Qup, Qdw [m³/s]                               │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

### 支配方程式

#### 1. 壁体内の熱移動（フーリエの法則）

```
q = -λ × (∂T/∂x)

q   : 熱流束 [W/m²]
λ   : 熱伝導率 [W/(m·K)]
T   : 温度 [K]
```

#### 2. 壁体内の水蒸気移動（フィックの法則）

```
jv = -δp × (∂pv/∂x)

jv  : 水蒸気流束 [kg/(m²·s)]
δp  : 湿気伝導率 [kg/(m·s·Pa)]
pv  : 水蒸気圧 [Pa]
```

#### 3. 換気による熱・水分交換

```
H_vent = Q × ρ × cp × ΔT
J_vent = Q × ρ × Δx

H_vent : 換気熱流 [W]
J_vent : 換気水分流 [kg/s]
Q      : 換気量 [m³/s]
ρ      : 空気密度 [kg/m³]
cp     : 空気比熱 [J/(kg·K)]
Δx     : 絶対湿度差 [kg/kg]
```

#### 4. 収支方程式

**熱収支：**
```
ρc × (∂T/∂t) = -∂q/∂x + S

ρc  : 体積熱容量 [J/(m³·K)]
S   : 発熱項（相変化熱など）
```

**水分収支：**
```
∂w/∂t = -∂jv/∂x - ∂jl/∂x

w   : 含水率 [kg/m³]
jl  : 液水流束 [kg/(m²·s)]
```


## 設定パラメータ

### 入力ファイル

| パラメータ | 説明 |
|-----------|------|
| `INPUT_ROOM` | 室条件CSV（容積、初期温湿度など） |
| `INPUT_WALL` | 壁条件CSV（構成、面積、熱伝達率など） |
| `INPUT_OPENING` | 開口条件CSV（換気量など） |
| `INPUT_CLIMATE` | 気象データCSV（外気温、湿度など） |

### 計算条件

| パラメータ | 説明 | 推奨値 |
|-----------|------|--------|
| `DT` | 時間刻み [hour] | 0.1（6分） |
| `START_DATE` | 計算開始日時 | - |
| `END_DATE` | 計算終了日時 | - |
| `OUTPUT_INTERVAL` | 出力間隔 [hour] | 10.0 |

### 初期条件

| パラメータ | 説明 |
|-----------|------|
| `USE_CUSTOM_INITIAL` | カスタム初期条件を使用するか |
| `INITIAL_TEMP` | 初期温度 [℃] |
| `INITIAL_RH` | 初期相対湿度 [-] |

## 出力ファイル

```
output_data/{CASE_NAME}/{timestamp}/
├── settings.txt              # 計算条件の記録
├── result_all_rooms.csv      # 全室の温度・湿度・絶対湿度
├── result_wall1.csv          # 壁体1の内部温湿度分布
├── result_room_analysis1.csv # 室1の熱収支分析
└── result_room_analysis2.csv # 室2の熱収支分析
```

### result_all_rooms.csv の内容

| カラム | 説明 |
|--------|------|
| date | 日時 |
| temp_outdoor | 外気温 [℃] |
| temp_indoor | 室内温度 [℃] |
| rh_outdoor | 外気相対湿度 [%] |
| rh_indoor | 室内相対湿度 [%] |
| ah_outdoor | 外気絶対湿度 [kg/kg] |
| ah_indoor | 室内絶対湿度 [kg/kg] |

### result_wall*.csv の内容

| カラム | 説明 |
|--------|------|
| date | 日時 |
| temp_1 ~ temp_n | 各セルの温度 [℃] |
| rh_1 ~ rh_n | 各セルの相対湿度 [%] |
| phi_1 ~ phi_n | 各セルの含水率 [kg/m³] |

## パターン別シミュレーション

異なる条件でシミュレーションを行う場合は、`main.jl` をコピーして設定セクションを変更してください：

```julia
# 例：換気強パターン
const INPUT_OPENING = "input_data/.../opening-condition/03-high-ventilation-model.csv"
const CASE_NAME = "case_high_ventilation"
```

## 注意事項

1. **時間刻み**: `DT` が大きすぎると計算が不安定になる可能性があります
2. **結露警告**: 壁体内部で結露が発生すると警告が表示されます
3. **計算時間**: 6ヶ月分の計算には約30分程度かかります（dt=0.1h の場合）
