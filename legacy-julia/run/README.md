# 建物内温湿度環境解析 - 実行ファイル

## 概要

このディレクトリには、建物ネットワークモデル（BNM: Building Network Model）による熱水分同時移動解析の実行ファイルが格納されています。

## 実行ファイル

| ファイル | 用途 |
|----------|------|
| `main.jl` | 単一パターン実行（設定をコード内で指定） |
| `main-all.jl` | 全75パターン一括実行（直列） |
| `main-all-parallel.jl` | 全75パターン並列実行（推奨） |
| `logger.jl` | ログ出力モジュール |

## 実行方法

### 単一パターン実行

```bash
# legacy-julia ディレクトリから
julia run/main.jl
```

### 全パターン一括実行（直列）

```bash
# legacy-julia ディレクトリから
julia run/main-all.jl
```

### 全パターン並列実行（推奨）

```bash
# legacy-julia ディレクトリから（4スレッドの場合）
julia -t 4 run/main-all-parallel.jl

# 利用可能な全コアを使用
julia -t auto run/main-all-parallel.jl
```

5(壁体) × 5(換気) × 3(気候) = **75パターン**を自動実行します。

#### 機能

- **進捗確認**: `_progress.txt` をリアルタイムで確認可能

**直列実行 (main-all.jl):**
- 1パターン: 約30分（1年分, dt=0.1h）

**並列実行 (main-all-parallel.jl):**
- 4スレッド: 約9〜10時間（約4倍速）

※ 実際の速度向上はCPUコア数とメモリ帯域に依存

## 計算の物理的背景

### 解析対象

建物内の温湿度環境を、以下の4要素のネットワークとしてモデル化：

```
┌─────────────────────────────────────────────────────────────┐
│                    BNM (Building Network Model)              │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│    ┌──────────┐         壁体          ┌──────────┐         │
│    │  外気    │ ←─────────────────→ │   室内   │         │
│    │ (Climate)│    熱流 q [W/m²]      │  (Room)  │         │
│    │          │    水蒸気流 jv        │          │         │
│    └────┬─────┘    液水流 jl          └────┬─────┘         │
│         │                                   │              │
│         └───────────── 換気 ─────────────────┘              │
│              Qup, Qdw [m³/s]                               │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

### 支配方程式

#### 1. 壁体内の熱移動（フーリエの法則）

```
q = -λ × (∂T/∂x)

q   : 熱流束 [W/m²]
λ   : 熱伝導率 [W/(m·K)]
T   : 温度 [K]
```

#### 2. 壁体内の水蒸気移動（フィックの法則）

```
jv = -δp × (∂pv/∂x)

jv  : 水蒸気流束 [kg/(m²·s)]
δp  : 湿気伝導率 [kg/(m·s·Pa)]
pv  : 水蒸気圧 [Pa]
```

#### 3. 換気による熱・水分交換

```
H_vent = Q × ρ × cp × ΔT
J_vent = Q × ρ × Δx

H_vent : 換気熱流 [W]
J_vent : 換気水分流 [kg/s]
Q      : 換気量 [m³/s]
ρ      : 空気密度 [kg/m³]
cp     : 空気比熱 [J/(kg·K)]
Δx     : 絶対湿度差 [kg/kg]
```

#### 4. 収支方程式

**熱収支：**
```
ρc × (∂T/∂t) = -∂q/∂x + S

ρc  : 体積熱容量 [J/(m³·K)]
S   : 発熱項（相変化熱など）
```

**水分収支：**
```
∂w/∂t = -∂jv/∂x - ∂jl/∂x

w   : 含水率 [kg/m³]
jl  : 液水流束 [kg/(m²·s)]
```

## 設定パラメータ

### 入力ファイル

| パラメータ | 説明 |
|-----------|------|
| `INPUT_ROOM` | 室条件CSV（容積、初期温湿度など） |
| `INPUT_WALL` | 壁条件CSV（構成、面積、熱伝達率など） |
| `INPUT_OPENING` | 開口条件CSV（換気量など） |
| `INPUT_CLIMATE` | 気象データCSV（外気温、湿度など）<br>京都/沖縄/札幌から選択可 |

### 計算条件

| パラメータ | 説明 | 推奨値 |
|-----------|------|--------|
| `DT` | 時間刻み [hour] | 0.1（6分） |
| `START_DATE` | 計算開始日時 | - |
| `END_DATE` | 計算終了日時 | - |
| `OUTPUT_INTERVAL` | 出力間隔 [hour] | 10.0 |

### 初期条件

| パラメータ | 説明 |
|-----------|------|
| `USE_CUSTOM_INITIAL` | カスタム初期条件を使用するか |
| `INITIAL_TEMP` | 初期温度 [℃] |
| `INITIAL_RH` | 初期相対湿度 [-] |

## パターン別シミュレーション

異なる条件でシミュレーションを行う場合は、`main.jl` をコピーして設定セクションを変更してください：

```julia
# 例：換気強パターン
const INPUT_OPENING = "input_data/.../opening-condition/03-high-ventilation-model.csv"
const CASE_NAME = "case_high_ventilation"
```

## 注意事項

1. **時間刻み**: `DT` が大きすぎると計算が不安定になる可能性があります
2. **結露警告**: 壁体内部で結露が発生すると警告が表示されます
3. **計算時間**: 6ヶ月分の計算には約30分程度かかります（dt=0.1h の場合）
