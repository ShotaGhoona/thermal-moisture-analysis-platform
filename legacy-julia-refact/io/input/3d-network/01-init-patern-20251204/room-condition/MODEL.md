# Room Condition - パターン別解説

---

## 共通モデル (01-base-model.csv)

※ 室条件は全パターン共通（壁構成・換気量のみ変更）

### 一室モデル概要図
```
                        外気 (rooms[1])
                             num = 1
                               |
         +---------------------+---------------------+
         |                     |                     |
         |    換気 (Opening)   |   壁体 (Wall)       |
         |                     |                     |
         v                     v                     v
    +--------------------------------------------------------+
    |                                                        |
    |                  室内 (rooms[2])                       |
    |                       num = 2                          |
    |                                                        |
    +--------------------------------------------------------+
```

### 室の寸法
```
    +─────────────────────────────────────────+
    |                 平面図                  |
    |                                         |
    |         5.0 m                           |
    |       <───────>                         |
    |       ┌───────┐   ^                     |
    |       │       │   │                     |
    |       │       │   │ 5.0 m               |
    |       │       │   │                     |
    |       └───────┘   v                     |
    |                                         |
    +─────────────────────────────────────────+

    +─────────────────────────────────────────+
    |                 断面図                  |
    |                                         |
    |       ┌───────┐   ^                     |
    |       │       │   │ 2.5 m (天井高)      |
    |       └───────┘   v                     |
    |                                         |
    +─────────────────────────────────────────+
```

### パラメータ
```
    ファイル  : 01-base-model.csv
    num       : 2
    name      : indoor
    幅        : 5.0 m
    奥行      : 5.0 m
    高さ      : 2.5 m
    床面積    : 25.0 m²
    容積      : 62.5 m³
```

### 初期条件
```
    温度      : 25.0 ℃
    相対湿度  : 50.0 %
```

### 室内負荷
```
    Qs        : 0 W     (室内発熱量)
    Js        : 0 kg/s  (室内発湿量)
    AC        : OFF     (空調)
```

---

## rooms配列の構造

```
    rooms[1] = outdoor (外気)
               │
               └─→ climate.air とリンク
                   （気象データから温湿度が自動更新される）

    rooms[2] = indoor (室内)
               │
               └─→ 解析対象
                   （計算により温湿度が変化する）
```

---

## 備考

- 室条件は全パターン（P0〜P4）で共通
- 壁構成・換気量の違いによる室内温湿度応答の違いを比較するため
- num=1 は外気として固定（CSVに記載不要）
