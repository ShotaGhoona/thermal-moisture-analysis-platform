## 使用カラム

**カラム1-6のみ使用**。それ以外は計算に使用しないため適当な値でOK。

| カラム | 変数名 | 使用 | 備考 |
|-------|-------|-----|------|
| 1 | BC | **使用** | 枝番号 |
| 2 | IP | **使用** | 上流側室番号 |
| 3 | IM | **使用** | 下流側室番号 |
| 4 | Type | **使用** | constant固定 |
| 5 | Qup | **使用** | 換気量 |
| 6 | Qdw | **使用** | 換気量 |
| 7-23 | ION〜V_SM | 不使用 | 適当な値でOK |

## パターン比較表

| 変数 | 単位 | P0 標準換気 | P1 換気弱 | P2 換気強 | P3 無換気 | P4 storage |
|-----|------|------------|----------|----------|----------|------------|
| BC | - | 1 | - | - | - | - |
| IP | - | 1 (outdoor) | - | - | - | - |
| IM | - | 2 (indoor) | - | - | - | - |
| Type | - | constant | - | - | - | - |
| Qup | m³/s | 0.005 | 0.0015 | 0.020 | 0.0 | 0.010 |
| Qdw | m³/s | 0.005 | 0.0015 | 0.020 | 0.0 | 0.010 |
| 目標換気回数 n | 1/h | 0.5 | 0.1 | 1.0 | 0.0 | 2.0 |
| B | - | (無視) | - | - | - | - |
| S | - | (無視) | - | - | - | - |
| A | m² | (無視) | - | - | - | - |
| HU,HD,alpha | - | (無視) | - | - | - | - |

## 備考

- Type=constant: 換気量固定（Qup, Qdw で直接指定）
- **カラム7以降（ION, DIR_IP, DIR_IM, B, S, HU, HD, M, MM, alpha, A, SV, SH, QV, QH, WC, V_SM）は計算に使用しないため、適当な値を入力してください**
