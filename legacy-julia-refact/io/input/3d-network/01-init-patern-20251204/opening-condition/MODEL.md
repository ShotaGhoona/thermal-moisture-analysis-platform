## 共通設定（全パターン）

### 接続
```
    IP = 1 (外気)
    IM = 2 (室内)
```

### 換気タイプ
```
    Type = "constant"
    → 換気量を直接指定するモード
    → Qup = Qdw（質量保存）
```

### 使用カラム
```
    BC, IP, IM, Type, Qup, Qdw のみ使用
    カラム7以降は計算に使用しない
```
