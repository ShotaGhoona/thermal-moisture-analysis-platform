## Phase 2: modules/physics/ を切り出す

**状態: 完了**

### ディレクトリ構造

```
modules/physics/
├── Physics.jl              # 統合モジュール
├── core/                   # 基盤
│   ├── constants.jl        # 物理定数
│   └── utils.jl            # ユーティリティ関数
├── properties/             # 物性計算
│   └── psychrometrics.jl   # 湿り空気の物性
├── flux/                   # 流量計算
│   ├── heat.jl             # 熱移動（伝導・伝達）
│   ├── vapor.jl            # 水蒸気移動
│   └── liquid.jl           # 液水移動
└── balance/                # 状態更新
    └── balance.jl          # 収支方程式
```

### サブディレクトリの役割

| ディレクトリ | 役割 | 内容 |
|-------------|------|------|
| `core/` | 基盤 | 物理定数、共通関数 |
| `properties/` | 物性計算 | 湿り空気の物性（飽和水蒸気圧、湿度変換） |
| `flux/` | 流量計算 | 熱・水蒸気・液水の移動現象 |
| `balance/` | 状態更新 | セル・室空気の収支方程式 |

### ファイル詳細

| ファイル | 内容 |
|---------|------|
| Physics.jl | 全サブモジュールの統合・エクスポート |
| core/constants.jl | R_VAPOR, GRAVITY, C_WATER 等 |
| core/utils.jl | harmonic_mean, transmittance, lewis_aldm |
| properties/psychrometrics.jl | cal_Pvs, convertRH2Miu, cal_DPvDT 等 |
| flux/heat.jl | latent_heat, heat_conduction, heat_transfer |
| flux/vapor.jl | vapor_permeance_*, vapor_transfer_* |
| flux/liquid.jl | liquid_conduction_potential |
| balance/balance.jl | update_temp_cell, update_miu_cell, update_ah_air |

### 移行マッピング

| 移行元（legacy-julia） | 移行先（legacy-julia-refact） |
|----------------------|------------------------------|
| module/function/vapour.jl | properties/psychrometrics.jl |
| module/function/lewis_relation.jl | core/utils.jl |
| module/function/flux_and_balance_equation.jl | flux/heat.jl, balance/balance.jl |
| module/transfer_in_media.jl（純粋関数部分） | flux/heat.jl, flux/vapor.jl, flux/liquid.jl |
| module/cell.jl（収支方程式部分） | balance/balance.jl |
| module/air.jl（収支方程式部分） | balance/balance.jl |

### 設計方針

1. **純粋関数のみ**: 構造体（Cell, Air, BC_Robin等）に依存しない
2. **Float64引数**: 全て基本型の引数・戻り値
3. **単体テスト可能**: 独立した関数として検証可能
4. **物理的意味の明確化**: docstringで単位・意味を記載
5. **役割別ディレクトリ**: core/properties/flux/balance の4分類

## Phase 3: modules/model/ を整理する

**状態: 完了**

### ディレクトリ構造

```
modules/model/
├── Model.jl                # 統合モジュール
├── types/                  # 型定義
│   ├── cell.jl             # Cell
│   ├── air.jl              # Air
│   ├── room.jl             # Room
│   ├── wall.jl             # Wall
│   ├── opening.jl          # Opening
│   └── climate.jl          # Climate, Location
├── boundary/               # 境界条件
│   └── conditions.jl       # BCDirichlet, BCNeumann, BCRobin
└── network/                # ネットワークモデル
    └── bnm.jl              # BuildingNetwork
```

### サブディレクトリの役割

| ディレクトリ | 役割 | 内容 |
|-------------|------|------|
| `types/` | 基本型定義 | Cell, Air, Room, Wall, Opening, Climate |
| `boundary/` | 境界条件 | 3種類の境界条件（Dirichlet, Neumann, Robin） |
| `network/` | ネットワーク | BuildingNetwork（室・壁・開口の接続構造） |

### ファイル詳細

| ファイル | 内容 |
|---------|------|
| Model.jl | 全サブモジュールの統合・エクスポート |
| types/cell.jl | Cell（壁体セル）、寸法・状態量・材料 |
| types/air.jl | Air（室空気）、温湿度・収支値 |
| types/room.jl | Room（室）、Air合成・内部発熱 |
| types/wall.jl | Wall（壁体）、セル配列・接続情報 |
| types/opening.jl | Opening（開口）、OpeningKind enum |
| types/climate.jl | Climate・Location（気象・地点情報） |
| boundary/conditions.jl | BCDirichlet, BCNeumann, BCRobin |
| network/bnm.jl | BuildingNetwork、インシデンス行列 |

### 移行マッピング

| 移行元（legacy-julia） | 移行先（legacy-julia-refact） |
|----------------------|------------------------------|
| module/cell.jl（struct部分） | types/cell.jl |
| module/air.jl（struct部分） | types/air.jl |
| module/room.jl（struct部分） | types/room.jl |
| module/wall.jl（struct部分） | types/wall.jl |
| module/opening.jl（struct部分） | types/opening.jl |
| module/climate.jl（struct部分） | types/climate.jl |
| module/boundary_condition.jl（struct部分） | boundary/conditions.jl |
| module/building_network_model.jl | network/bnm.jl |

### 設計方針

1. **型定義のみ**: 計算ロジックは含めない（solver/へ）
2. **immutable優先**: BCDirichlet, BCNeumann, Location は immutable
3. **Symbol活用**: 材料名は `:concrete` のように Symbol で高速比較
4. **enum活用**: OpeningKind を enum 化で型安全に
5. **命名統一**: `IP/IM` → `room_id_plus/room_id_minus` 等

## Phase 4: modules/solver/ を分割する

**状態: 完了**

### ディレクトリ構造

```
modules/solver/
├── Solver.jl               # 統合モジュール（128行）
├── flux/                   # 流量計算
│   ├── wall_flux.jl        # 壁体熱・水分流量（385行）
│   └── ventilation_flux.jl # 換気流量（272行）
├── balance/                # 収支・更新
│   ├── cell_updater.jl     # セル状態更新（215行）
│   └── air_updater.jl      # 空気状態更新（170行）
└── control/                # 制御
    ├── condensation.jl     # 結露判定（205行）
    └── stepper.jl          # 時間ステップ制御（232行）
```

### サブディレクトリの役割

| ディレクトリ | 役割 | 内容 |
|-------------|------|------|
| `flux/` | 流量計算 | 壁体・換気の熱・水分流量 |
| `balance/` | 状態更新 | セル・室空気の温度・湿度更新 |
| `control/` | 制御 | 時間進行、結露判定 |

### ファイル詳細

| ファイル | 行数 | 内容 |
|---------|------|------|
| Solver.jl | 128 | 全サブモジュールの統合・エクスポート |
| wall_flux.jl | 385 | Cell-Cell/Cell-BC間の熱・水蒸気・液水流束、多重ディスパッチ |
| ventilation_flux.jl | 272 | 自然換気・機械換気の流量計算、熱・水分輸送 |
| cell_updater.jl | 215 | セルの温度・水分化学ポテンシャル更新（Forward Euler） |
| air_updater.jl | 170 | 室空気の温度・相対湿度更新 |
| condensation.jl | 205 | 表面/内部結露の判定と処理 |
| stepper.jl | 232 | 1タイムステップの統合計算、CFL条件チェック |

### 移行マッピング

| 移行元（legacy-julia） | 移行先（legacy-julia-refact） |
|----------------------|------------------------------|
| transfer_in_media.jl: cal_q/jv/jl | flux/wall_flux.jl |
| flux_ventilation.jl | flux/ventilation_flux.jl |
| cell.jl: cal_newtemp/miu | balance/cell_updater.jl |
| air.jl: cal_newtemp/RH | balance/air_updater.jl |
| main.jl: 時間ループ | control/stepper.jl |
| main.jl: 結露処理 | control/condensation.jl |

### 設計方針

1. **Model依存**: 構造体はModelから取得
2. **Physics利用**: 純粋な物理計算はPhysicsから呼び出し
3. **多重ディスパッチ**: Cell-Cell, Cell-BC, BC-Cell の組み合わせに対応
4. **暫定材料物性**: Phase 5でMaterialsモジュールに移行予定
