# legacy-julia 機能紹介

## 概要

legacy-juliaは、建物内の温湿度環境を**Building Network Model (BNM)**という微気候予測手法で解析するJulia製シミュレーションシステムです。

元々は壁体一枚の熱・水分移動をシミュレーションするために作成されましたが、現在は以下のような多機能なシステムに発展しています。

---

## 主要機能一覧

### 1. 熱・水分同時移動解析

壁体内における熱と水分（水蒸気・液水）の同時移動を解析します。

- **熱移動**: フーリエの法則に基づく熱伝導
- **水蒸気移動**: フィックの法則に基づく拡散
- **液水移動**: 毛管圧勾配と重力による移動

```
支配方程式:
  熱: ρ·c·∂T/∂t = -∂q/∂x + S（相変化熱）
  水分: ∂w/∂t = -∂jv/∂x - ∂jl/∂x
```

### 2. 室空気の温湿度変化計算

室空間の温度・湿度の時間変化を計算します。

- 壁体からの熱・水分流入
- 換気による熱・水分流入
- 内部発熱・発湿源

### 3. 多様な壁体構成への対応

31種類の建築材料に対応し、様々な壁体構成をシミュレーション可能です。

| カテゴリ | 材料例 |
|---------|--------|
| 躯体材料 | コンクリート、モルタル |
| 断熱材 | グラスウール、XPS、硬質ウレタン |
| 内装材 | 石膏ボード、合板 |
| 自然素材 | 土壁、藁材、和紙 |
| 特殊 | 通気層、防水シート、調湿材 |

### 4. 複数換気パターンへの対応

換気条件を柔軟に設定可能です。

| パターン | 説明 |
|---------|------|
| 基準換気 | 標準的な換気量 |
| 低換気 | 換気量を抑制 |
| 高換気 | 換気量を増加 |
| 無換気 | 完全密閉 |
| 蔵換気 | 伝統的蔵の換気パターン |

### 5. 複数都市の気象データ対応

日本国内3都市の気象データに対応しています。

- **京都**: 温暖湿潤気候（-2〜35℃）
- **沖縄**: 亜熱帯気候（13〜31℃）
- **札幌**: 亜寒帯気候（-14〜31℃）

### 6. バッチ実行機能

75パターン（5壁体 × 5換気 × 3気候）を自動で連続実行します。

- **直列実行**: main-all.jl
- **並列実行**: main-all-parallel.jl（マルチスレッド対応）

### 7. 進捗管理・再開機能

- リアルタイム進捗表示（プログレスバー）
- 中断後の再開機能（完了済みパターンをスキップ）
- エラー発生時も残りのパターンを継続実行

### 8. 詳細なロギング機能

3種類の出力ファイルを生成します。

| ファイル | 内容 |
|---------|------|
| result_all_rooms.csv | 全室の温度・湿度時系列 |
| result_wall*.csv | 壁体内の温湿度分布 |
| result_room_analysis*.csv | 熱収支・水分収支の詳細 |

### 9. 結露判定機能

- 表面結露の検出と記録
- 内部結露の警告出力

## 計算パラメータ

| パラメータ | デフォルト値 | 説明 |
|----------|------------|------|
| タイムステップ | 0.1時間（6分） | 計算の時間刻み |
| 出力間隔 | 10時間 | ファイル書き出し間隔 |
| 計算期間 | 1年間 | 2022/4/1〜2023/4/1 |

## 技術的特徴

- **数値解法**: Forward Euler（陽解法）
- **空間離散化**: 有限差分法（FDM）、セル中心配置
- **プログラミング言語**: Julia（高速数値計算）
