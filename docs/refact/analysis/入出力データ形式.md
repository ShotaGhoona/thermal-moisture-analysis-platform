# legacy-julia 入出力データ形式

## 入力データ

### 1. 室条件 (room-condition/*.csv)

室空間の初期条件を定義します。

**ファイル例**: `01-base-model.csv`

```csv
室番号, 室名, 容積[m³], 温度[℃], 湿度[%], 室高さ[m], 顕熱量[W], 湿気量[kg/s], AC有無
num, name, vol, temp, rh, Hight, Qs, Js, AC
1, outdoor, 1000, 20, 60, 0, 0, 0, OFF
2, indoor, 62.5, 25, 50, 2.5, 0, 0, OFF
```

**カラム説明**:

| カラム | 単位 | 説明 |
|-------|------|------|
| num | - | 室番号（1から連番） |
| name | - | 室名 |
| vol | m³ | 室容積 |
| temp | ℃ | 初期温度 |
| rh | % | 初期相対湿度 |
| Hight | m | 室高さ |
| Qs | W | 顕熱発生量 |
| Js | kg/s | 湿気発生量 |
| AC | - | 空調有無（ON/OFF） |

**備考**:
- Room 1は外気として扱われ、気象データとリンク
- Room 2以降が計算対象の室空間

---

### 2. 壁条件 (wall-condition/*.csv)

壁体の構成を定義します。

**5パターン**:
| ファイル | 内容 |
|---------|------|
| 01-base-model.csv | RC単体（厚150mm） |
| 02-rc-inner-insulation.csv | RC内断熱 |
| 03-rc-outer-insulation.csv | RC外断熱 |
| 04-rc-inner-insulation-hygroscopic.csv | RC内断熱+調湿材 |
| 05-mud-wall.csv | 土壁 |

**ヘッダー形式**:
```csv
壁番号, IP, IM, Type, 分割数, 材料名, 初期温度[℃], 初期湿度[%], 厚さ[m], 面積[m²], 傾斜角[°], 上流方位, 下流方位, 対流熱伝達率_IP, 対流熱伝達率_IM, 放射熱伝達率_IP, 放射熱伝達率_IM, ...

num, IP, IM, Type, div_num, material_name, temp, rh, thickness, area, ION, dir_IP, dir_IM, alphac_IP, alphac_IM, alphar_IP, alphar_IM, ...
```

**カラム説明**:

| カラム | 単位 | 説明 |
|-------|------|------|
| num | - | 壁番号 |
| IP | - | 上流側室番号（0=外気） |
| IM | - | 下流側室番号 |
| Type | - | 壁タイプ（数値:自動分割、文字列:cell_data参照） |
| div_num | - | 分割数（Type=数値の場合） |
| material_name | - | 材料名 |
| temp | ℃ | 初期温度 |
| rh | % | 初期相対湿度 |
| thickness | m | 壁厚さ |
| area | m² | 壁面積 |
| ION | ° | 傾斜角（90=垂直壁） |
| dir_IP | - | 上流側方位（N/S/E/W） |
| dir_IM | - | 下流側方位 |
| alphac_IP | W/(m²·K) | 上流側対流熱伝達率 |
| alphac_IM | W/(m²·K) | 下流側対流熱伝達率 |
| alphar_IP | W/(m²·K) | 上流側放射熱伝達率 |
| alphar_IM | W/(m²·K) | 下流側放射熱伝達率 |

**デフォルト熱伝達率**:
- 外表面: 19 W/(m²·K)
- 内表面: 4.9 W/(m²·K)（対流）、4.4 W/(m²·K)（放射）

---

### 3. 開口条件 (opening-condition/*.csv)

換気経路を定義します。

**5パターン**:
| ファイル | 内容 |
|---------|------|
| 01-base-model.csv | 基準換気（0.005 m³/s） |
| 02-low-ventilation-model.csv | 低換気 |
| 03-high-ventilation-model.csv | 高換気 |
| 04-no-ventilation-model.csv | 無換気（Q=0） |
| 05-storage-ventilation-model.csv | 蔵換気 |

**ヘッダー形式**:
```csv
枝番号, IP, IM, Type, Qup[m³/s], Qdw[m³/s], ION, DIR_IP, DIR_IM, ...

BC, IP, IM, Type, Qup, Qdw, ION, DIR_IP, DIR_IM, ...

1, 1, 2, constant, 0.005, 0.005, VT, S, N, ...
```

**カラム説明**:

| カラム | 単位 | 説明 |
|-------|------|------|
| BC | - | 開口番号 |
| IP | - | 上流側室番号 |
| IM | - | 下流側室番号 |
| Type | - | 換気タイプ（"constant"=定風量） |
| Qup | m³/s | 上流→下流の風量 |
| Qdw | m³/s | 下流→上流の風量 |
| ION | - | 開口の向き（VT=垂直） |
| DIR_IP | - | 上流側方位 |
| DIR_IM | - | 下流側方位 |

---

### 4. 気象データ (climate-data/*.csv)

1年分の気象データを定義します。

**3都市**:
| ファイル | 都市 | 温度範囲 |
|---------|------|---------|
| climate_data_kyoto.csv | 京都 | -2〜35℃ |
| climate_data_okinawa.csv | 沖縄 | 13〜31℃ |
| climate_data_sapporo.csv | 札幌 | -14〜31℃ |

**期間**: 2022/4/1 00:00 〜 2023/4/1 00:00（4月スタート、8760時間）

**ヘッダー形式**:
```csv
日時, 気温[℃], 相対湿度[%], 気圧[Pa], 降水量[mm/h], 積雪量[mm/h], 風速[m/s], 風向, 日射量[W/m²], 大気透過率, 雲量

date, temp, rh, p_atm, Jp, Js, WS, WD, Qs, tau, cloudiness
2022/4/1 0:00, 10.9, 60, , 0.0, , 1.1, 東, 0, 1.0e-50,
```

**カラム説明**:

| カラム | 単位 | 説明 |
|-------|------|------|
| date | - | 日時（yyyy/m/d H:MM） |
| temp | ℃ | 外気温 |
| rh | % | 相対湿度 |
| p_atm | Pa | 大気圧 |
| Jp | mm/h | 降水量 |
| Js | mm/h | 積雪量 |
| WS | m/s | 風速 |
| WD | - | 風向（日本語） |
| Qs | W/m² | 日射量 |
| tau | - | 大気透過率 |
| cloudiness | - | 雲量 |

## 出力データ

### 1. result_all_rooms.csv（全室の温湿度）

全室の時系列データを出力します。

**フォーマット**:
```csv
, room1, room1, room1, room2, room2, room2
 , temp, rh, ah, temp, rh, ah
2022/04/01 00:00, 10.9, 0.89, 0.00721, 25.0, 0.5, 0.00988
2022/04/01 00:10, 10.705, 0.893, 0.00714, 10.2, 0.549, 0.00422
```

**カラム説明**:

| カラム | 単位 | 説明 |
|-------|------|------|
| date | - | 日時 |
| temp | ℃ | 温度 |
| rh | - | 相対湿度（0〜1） |
| ah | kg/kg | 絶対湿度 |

---

### 2. result_wall*.csv（壁体内の温湿度分布）

壁体の各セルの状態を出力します。

**フォーマット**:
```csv
, climate, climate, climate, climate, wall1, wall1, wall1, wall1, ..., indoor, indoor, indoor, indoor
 , temp, rh, ah, phi, temp, rh, ah, phi, ..., temp, rh, ah, phi
2022/04/01 00:00, 10.9, 0.89, 0.00721, Error, 10.0, 0.56, 0.00425, 0.05131, ..., 25.0, 0.5, 0.00988, Error
```

**カラム説明**:

| カラム | 単位 | 説明 |
|-------|------|------|
| temp | ℃ | 温度 |
| rh | - | 相対湿度（0〜1） |
| ah | kg/kg | 絶対湿度 |
| phi | kg/m³ | 含水率（材料のみ、空気は"Error"） |

**構成**:
- climate: 外気の状態
- wall1〜wallN: 各セルの状態
- indoor: 内室の状態

---

### 3. result_room_analysis*.csv（室の熱収支分析）

室ごとの詳細な収支データを出力します。

**ヘッダー形式（2行）**:
```
第1行: [空白], room1(3列), wall1_IP(6列), wall1_IM(6列), ..., opening1(3列), ..., Heat source(2列)
第2行: [空白], temp/rh/ah, temp/rh/ah/Hw/Jwv/Jwl, ..., Hv/Jv, ..., Hin/Jin
```

**記録項目**:

| 対象 | カラム | 説明 |
|------|-------|------|
| 室 | temp, rh, ah | 室の温度・相対湿度・絶対湿度 |
| 壁体表面 | temp, rh, ah | 表面の状態 |
| 壁体表面 | Hw | 熱流量 [W] |
| 壁体表面 | Jwv | 水蒸気流量 [kg/s] |
| 壁体表面 | Jwl | 液水流量 [kg/s] |
| 開口 | temp, rh, ah | 相手室の状態 |
| 開口 | Hv | 換気熱流 [W] |
| 開口 | Jv | 換気水分流 [kg/s] |
| 発熱源 | Hin | 顕熱発生量 [W] |
| 発熱源 | Jin | 湿気発生量 [kg/s] |

---

### 4. settings.txt（計算条件）

各パターンの計算条件を記録します。

```
=== 計算設定 ===
計算開始時刻: 2024/12/24 10:30:00
ケースID: w01-base_o01-base_kyoto

入力ファイル:
  室条件: room-condition/01-base-model.csv
  壁条件: wall-condition/01-base-model.csv
  換気条件: opening-condition/01-base-model.csv
  気象データ: climate-data/climate_data_kyoto.csv

計算条件:
  開始日: 2022/4/1
  終了日: 2023/4/1
  時間刻み: 0.1 hour
  出力間隔: 10.0 hour
```

### 5. バッチ実行の管理ファイル

| ファイル | 内容 |
|---------|------|
| _progress.txt | 進捗（完了数、残り時間、プログレスバー） |
| _batch_log.txt | タイムスタンプ付きログ |
| _terminal_log.txt | ターミナル出力全体 |
| _summary.csv | 全パターンの成功/失敗一覧 |
| _completed.txt | 完了済みパターンリスト（再開用） |

**_summary.csv のカラム**:
```csv
case_id, wall_id, wall_name, opening_id, opening_name, climate_id, climate_name, status, duration_sec, start_time, end_time, error_message
```
