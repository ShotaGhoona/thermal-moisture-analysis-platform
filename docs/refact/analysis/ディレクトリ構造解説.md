# legacy-julia ディレクトリ構造解説

## 全体構造

```
legacy-julia/
├── run/                          # 実行ファイル
├── module/                       # 計算モジュール
├── input_data/                   # 入力データ
└── output_data/                  # 出力データ
```

---

## run/ - 実行ファイル

メインの実行スクリプトとロガーが格納されています。

```
run/
├── main.jl                  # 単一パターン実行
├── main-all.jl              # 全パターン直列実行（75パターン）
├── main-all-2.jl            # 別設定の直列実行
├── main-all-3.jl            # 別設定の直列実行
├── main-all-parallel.jl     # 全パターン並列実行
├── logger.jl                # ロギング機能
└── README.md                # 使用方法・計算理論ドキュメント
```

| ファイル | 用途 |
|---------|------|
| main.jl | 1つのパターンを実行 |
| main-all.jl | 75パターンを順番に実行 |
| main-all-parallel.jl | マルチスレッドで並列実行 |
| logger.jl | 結果のCSV出力を管理 |

---

### 入力データの組み合わせ

| カテゴリ | パターン数 | 内容 |
|---------|----------|------|
| 壁体 | 5 | RC単体、内断熱、外断熱、調湿、土壁 |

## output_data/ - 出力データ

計算結果が格納されます。

```
output_data/
├── batch_all/                   # 直列実行結果
│   └── MMDD/                    # 実行日付フォルダ
│       ├── _progress.txt        # 進捗表示
│       ├── _batch_log.txt       # 実行ログ
│       ├── _summary.csv         # 全パターン結果一覧
│       ├── _completed.txt       # 完了済みリスト（再開用）
│       ├── _terminal_log.txt    # ターミナル出力
│       │
│       └── {case_id}/           # 各パターンの結果
│           ├── settings.txt
│           ├── result_all_rooms.csv
│           ├── result_wall1.csv
│           ├── result_wall2.csv
│           └── result_room_analysis1.csv
│
├── batch_all_2/                 # 並列実行結果その1
├── batch_all_3/                 # 並列実行結果その2
│
└── network_model/               # その他の実験結果
```

### 出力ファイルの説明

| ファイル | 内容 |
|---------|------|
| _progress.txt | 進捗（完了数、残り時間など） |
| _summary.csv | 全パターンの成功/失敗一覧 |
| _completed.txt | 完了済みパターン（再開時に参照） |
| result_all_rooms.csv | 全室の温湿度時系列 |
| result_wall*.csv | 壁体内の温湿度分布 |
| result_room_analysis*.csv | 熱収支・水分収支詳細 |

### ケースIDの命名規則

```
{wall_id}_{opening_id}_{climate_id}

例: w01-base_o02-low_kyoto
    │        │       └── 気候: 京都
    │        └── 換気: 低換気
    └── 壁体: RC単体
```
