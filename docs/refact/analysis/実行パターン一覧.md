# legacy-julia 実行パターン一覧

## パターン構成

75パターン = 5壁体 × 5換気 × 3気候

---

## 壁体パターン（5種類）

| ID | 名称 | 説明 | ファイル |
|----|------|------|---------|
| w01 | base | RC単体（厚150mm） | 01-base-model.csv |
| w02 | inner | RC内断熱 | 02-rc-inner-insulation.csv |
| w03 | outer | RC外断熱 | 03-rc-outer-insulation.csv |
| w04 | hygro | RC内断熱+調湿材 | 04-rc-inner-insulation-hygroscopic.csv |
| w05 | mud | 土壁 | 05-mud-wall.csv |

---

## 換気パターン（5種類）

| ID | 名称 | 説明 | 風量 | ファイル |
|----|------|------|------|---------|
| o01 | base | 基準換気 | 0.005 m³/s | 01-base-model.csv |
| o02 | low | 低換気 | 少 | 02-low-ventilation-model.csv |
| o03 | high | 高換気 | 多 | 03-high-ventilation-model.csv |
| o04 | none | 無換気 | 0 | 04-no-ventilation-model.csv |
| o05 | storage | 蔵換気 | 特殊 | 05-storage-ventilation-model.csv |

---

## 気候パターン（3都市）

| ID | 都市 | 温度範囲 | 特徴 | ファイル |
|----|------|---------|------|---------|
| kyoto | 京都 | -2〜35℃ | 温暖湿潤気候 | climate_data_kyoto.csv |
| okinawa | 沖縄 | 13〜31℃ | 亜熱帯気候 | climate_data_okinawa.csv |
| sapporo | 札幌 | -14〜31℃ | 亜寒帯気候 | climate_data_sapporo.csv |

---

## パターンID命名規則

```
{wall_id}_{opening_id}_{climate_id}

例: w01-base_o02-low_kyoto
    │        │       └── 気候: 京都
    │        └── 換気: 低換気
    └── 壁体: RC単体
```

## 実行コマンド

### 単一パターン実行

```bash
julia run/main.jl
```

### 全パターン直列実行

```bash
julia run/main-all.jl
```

### 全パターン並列実行

```bash
# 4スレッド
julia -t 4 run/main-all-parallel.jl

# 利用可能な全コア
julia -t auto run/main-all-parallel.jl
```

---

## 再開機能

中断した場合、`_completed.txt` に完了済みパターンが記録されます。
再実行すると、完了済みパターンをスキップして残りを実行します。

```
_completed.txt の内容例:
w01-base_o01-base_kyoto
w01-base_o02-low_kyoto
w01-base_o03-high_kyoto
```
