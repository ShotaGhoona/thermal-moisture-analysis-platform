## 概要

## 物性値の種類

各材料で以下の物性値が定義されています：

| 物性値 | 関数 | 単位 | 説明 |
|-------|------|------|------|
| 熱伝導率 | lam(φ, T) | W/(m·K) | 含水率・温度依存 |
| 湿気伝導率 | dp(φ, T) | kg/(m·s·Pa) | 水蒸気拡散係数 |
| 液水伝導率 | dw(φ, T) | kg/(m·s) | 毛管伝導率 |
| 密度 | row | kg/m³ | 乾燥密度 |
| 比熱容量 | C | J/(kg·K) | 乾燥比熱 |
| 含水率 | phi(miu) | kg/m³ | 水分化学ポテンシャルから計算 |
| 飽和含水率 | phi_max | kg/m³ | 最大含水率 |

---

## 物性値アクセス方法

`property_conversion.jl` を通じてアクセスします：

```julia
# 熱伝導率
lam = pc.get_lam(cell, "concrete_goran")

# 湿気伝導率
dp = pc.get_dp(cell, "glass_wool_16K")

# 含水率（miuから計算）
phi = pc.get_phi(cell, "mud_wall")

# 比熱容量
C = pc.get_C(cell, "plywood")

# 密度
row = pc.get_row(cell, "gypsum_board")
```

## 物性値の特徴

### コンクリート (concrete_goran)

- 高い熱容量（蓄熱性）
- 高い透湿抵抗
- Goran式による含水率依存物性

### グラスウール (glass_wool_*)

- 低い熱伝導率（高断熱性）
- 高い透湿性
- 密度により16K/24K/32Kの3グレード

### 土壁 (mud_wall)

- 高い調湿性能
- 温度・湿度による物性変化が大きい
- 伝統的建築材料

### 通気層 (vented_air_space)

- 特殊な扱い（熱抵抗・湿気抵抗として計算）
- 隣接セルを直接接続
- 液水移動なし
