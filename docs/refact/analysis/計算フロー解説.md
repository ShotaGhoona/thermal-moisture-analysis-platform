# legacy-julia 計算フロー解説

## 全体の計算フロー

```
入力データ読み込み
    ↓
モデル構築（BNM作成）
    ↓
時間ループ（1年分）
    ↓
結果出力
```

---

## 1. モデル構築フェーズ

`create_BNM_model()` 関数でモデルを構築します。

### ステップ1: CSVファイル読み込み

```julia
climate = input_climate_data(...)  # 気象データ（8760時間分）
rooms = input_room_data(...)       # 室情報
walls = input_wall_data(...)       # 壁体構成
openings = input_opening_data(...) # 開口・換気
```

### ステップ2: ポインタリンク設定

```julia
# 外気を最初の室にリンク
rooms[1].air = climate.air

# 壁体の境界条件に室空気をリンク
for wall in walls
    wall.BC_IP.air = rooms[wall.IP].air  # 上流側
    wall.BC_IM.air = rooms[wall.IM].air  # 下流側
end

# 開口に接続先室をリンク
for opening in openings
    opening.room_IP = rooms[opening.IP]
    opening.room_IM = rooms[opening.IM]
end
```

### ステップ3: インシデンス行列作成

室と壁体・開口の接続関係を行列で表現します。

```julia
IC_walls = zeros(length(rooms), length(walls))
for i in 1:length(walls)
    IC_walls[walls[i].IP, i] = +1.0  # 上流側
    IC_walls[walls[i].IM, i] = -1.0  # 下流側
end
```

### ステップ4: BNM構造体作成

```julia
return BNM(rooms, walls, openings, climate, IC_walls, IC_openings)
```

## 2. 時間ループの1ステップ

時間刻み `dt = 0.1時間（6分）` で計算を進めます。

```julia
while network_model.climate.date ≠ END_DATE
    # ステップ1: 気象データ補間
    reset_climate_data(network.climate)

    # ステップ2: 壁体の熱・水分流量計算
    cal_network_flux_of_wall(network)

    # ステップ3: 換気の熱・水分流量計算
    cal_network_flux_of_ventilation(network)

    # ステップ4: 新値計算
    cal_new_value_ver_network(network, dt)

    # ステップ5: 時間進行
    time_elapses(network.climate, dt)

    # ステップ6: 出力（間隔に応じて）
    write_data_to_logger(...)
end
```

## 3. 壁体の熱・水分流量計算

`cal_network_flux_of_wall()` で壁体内の流量を計算します。

### 対象配列

```julia
target_model = [BC_IP, Cell1, Cell2, ..., CellN, BC_IM]
```

### 隣接要素間の流量計算

```julia
for j in 1:length(target_model)-1
    # 通気層の場合
    if material_name(target_model[j+1]) == "vented_air_space"
        q  = (temp[j] - temp[j+2]) / Rth
        jv = (pv[j] - pv[j+2]) / Rdp
        jl = 0.0
    else
        # 通常の熱伝導・水分移動
        q  = cal_q(target_model[j], target_model[j+1])   # フーリエ則
        jv = cal_jv(target_model[j], target_model[j+1])  # フィック則
        jl = cal_jl(target_model[j], target_model[j+1], sin_angle)  # 毛管+重力
    end

    # 隣接セルに流量を設定
    if typeof(target_model[j]) == Cell
        target_model[j].Q[2][1]  = -q * area
        target_model[j].Jv[2][1] = -jv * area
        target_model[j].Jl[2][1] = -jl * area
    elseif typeof(target_model[j]) == BC_Robin
        # 境界層：室に流入
        add_H_wall(target_model[j].air, -q * wall_area)
        add_J_wall(target_model[j].air, -jv * wall_area)
    end
end
```

## 4. 換気の熱・水分流量計算

`cal_network_flux_of_ventilation()` で換気による流量を計算します。

```julia
for opening in network.openings
    if opening.Type == "constant"
        # 空気の比熱（水蒸気を含む）
        ca_IP = 1005.0 + 1846.0 * ah(room_IP)
        ca_IM = 1005.0 + 1846.0 * ah(room_IM)

        # 空気密度
        rho = 353.25 / mean_temp

        # 熱流量 [W]
        H_vent_IP = Qup * rho * ca_IM * (T_IM - T_IP)

        # 水分流量 [kg/s]
        J_vent_IP = Qup * rho * (ah_IM - ah_IP)

        add_H_vent(room_IP, H_vent_IP)
        add_J_vent(room_IP, J_vent_IP)
    end
end
```

## 5. 新値計算

`cal_new_value_ver_network()` で新しい温度・湿度を計算します。

### 5.1 壁体セルの更新

```julia
for wall in network.walls
    for j in 1:length(wall.cell)
        if material_name(wall.cell[j]) ≠ "vented_air_space"
            # 新温度（熱収支）
            new_temp = cal_newtemp(
                wall.cell[j],
                sum(sum(wall.cell[j].Q)),
                -sum(sum(wall.cell[j].Jv)),
                dt
            )
            wall.cell[j].temp = new_temp

            # 新水分ポテンシャル（水分収支）
            new_miu = cal_newmiu(
                wall.cell[j],
                sum(sum(wall.cell[j].Jv)),
                sum(sum(wall.cell[j].Jl)),
                dt
            )

            # 結露判定
            if new_miu >= -0.1
                new_miu = -0.1  # 飽和状態に制限
                # 表面または内部結露を記録
            end

            wall.cell[j].miu = new_miu
        end
    end
end
```

### 5.2 室空気の更新

```julia
for i in 2:length(network.rooms)  # i=1は外気（スキップ）
    # 温度更新
    Q_total = H_wall(room) + H_vent(room) + H_in(room)
    new_temp = cal_newtemp(room.air, Q_total, dt)
    set_temp(network.rooms[i], new_temp)

    # 相対湿度更新
    J_total = J_wall(room) + J_vent(room) + J_in(room)
    new_rh = cal_newRH(room.air, dt)
    set_rh(network.rooms[i], new_rh)
end
```

## 6. 収支方程式の詳細

### 温度の更新式

```
ρ·c·V·(T_new - T_old)/dt = Q_wall + Q_vent + Q_in

where:
  ρ = 353.25 / T     [kg/m³]（乾き空気）
  c = 1005 + 1846·ah [J/(kg·K)]（乾き空気＋水蒸気）
  V = 室容積 [m³]
  dt = タイムステップ [s]
  Q_wall = 壁からの熱流入 [W]
  Q_vent = 換気からの熱流入 [W]
  Q_in = 発熱源 [W]

よって:
  T_new = T_old + dt · (Q_wall + Q_vent + Q_in) / (ρ·c·V)
```

### 相対湿度の更新式

```
ρ·V·(ah_new - ah_old)/dt = J_wall + J_vent + J_in

where:
  ah = 絶対湿度 [kg/kg]
  J_wall = 壁からの水分流入 [kg/s]
  J_vent = 換気からの水分流入 [kg/s]
  J_in = 発湿源 [kg/s]

ah_new計算後、RHはMagnus式で計算:
  rh_new = pv / pvs(T_new)
```

## 7. 計算の物理的背景

### 支配方程式

#### 熱移動（フーリエ則）
```
q = -λ·∂T/∂x

ρ·c·∂T/∂t = -∂q/∂x + S（相変化熱）
```

#### 水蒸気移動（フィック則）
```
jv = -δp·∂pv/∂x （圧力駆動）
jv = -δ·∂x/∂x  （ポテンシャル駆動）
```

#### 液水移動
```
jl = (毛管圧勾配) + (重力)
∂w/∂t = -∂jv/∂x - ∂jl/∂x
```

#### 室空気の温度変化
```
ρ·ca·V·∂T/∂t = H_wall + H_vent + H_in

where:
  ca = 1005 + 1846·ah（比熱：絶対湿度依存）
  V = 室容積
```

#### 室空気の湿度変化
```
ρ·V·∂ah/∂t = J_wall + J_vent + J_in
```

### 数値解法

| 項目 | 方法 |
|------|------|
| 時間積分 | Forward Euler（陽解法） |
| 時間刻み | dt = 0.1h = 360s |
| 空間離散化 | 有限差分法（FDM） |
| セル配置 | セル中心配置 |

### 結露判定

```
miu ≥ -0.1 で飽和状態と判定
```

- 表面結露: `jl_surf` に記録
- 内部結露: 警告を出力

## 9. 計算定数・パラメータ

| パラメータ | 値 | 単位 | 説明 |
|----------|-----|------|------|
| **時間設定** |
| DT | 0.1 | hour | タイムステップ（6分） |
| OUTPUT_INTERVAL | 10.0 | hour | ファイル出力間隔 |
| START_DATE | 2022/4/1 | - | 計算開始 |
| END_DATE | 2023/4/1 | - | 計算終了（1年間） |
| **空気物性** |
| cp_air | 1005.0 | J/(kg·K) | 乾き空気の比熱 |
| cp_vapor | 1846.0 | J/(kg·K) | 水蒸気の比熱係数 |
| Rv | 461.5 | J/(kg·K) | 水蒸気ガス定数 |
| ρ計算式 | 353.25/T | kg/m³ | ボイル・シャルルの法則 |
| **熱伝達率** |
| α_out | 19 | W/(m²·K) | 外表面対流 |
| α_in | 4.9 | W/(m²·K) | 内表面対流 |
| α_rad | 4.4 | W/(m²·K) | 放射 |
| **結露判定** |
| miu_threshold | -0.1 | J/kg | 飽和判定 |
