## システム概要

legacy-juliaは、建物内の温湿度環境を**Building Network Model (BNM)**という微気候予測手法で解析するJulia製シミュレーションシステムです。

### 主な機能

1. 壁体内の熱・水分同時移動解析
2. 室空気の温湿度変化計算
3. 31種類の建築材料対応
4. 複数換気パターン対応
5. 3都市の気象データ対応
6. 75パターンのバッチ実行
7. 並列実行対応

### 計算規模

- 1パターン: 約30分（1年分シミュレーション）
- 75パターン: 約37時間（直列）、約5-6時間（8スレッド並列）
- 出力データ: 1パターンあたり40-70MB

## リファクタリングに向けて

### 現状の課題

1. **コードの複雑化**: 機能追加により45KBの巨大モジュールが存在
2. **モジュール間の密結合**: 依存関係が複雑
3. **設定の分散**: 設定値がコード内に分散
4. **テストの不足**: 単体テストが未整備
5. **ドキュメント不足**: コード内コメントが少ない

### リファクタリング方針（案）

1. 巨大モジュールの分割
2. 設定ファイルの統一
3. テストの追加
4. 型システムの活用
5. エラーハンドリングの改善
