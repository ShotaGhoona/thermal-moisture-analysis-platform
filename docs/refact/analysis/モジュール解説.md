## 構造体定義モジュール

### 1. Air（air.jl）- 空気

室内空気・外気の状態を表現する構造体です。

```julia
struct Air
    name::String            # "room1", "climate"
    temp::Float64           # 温度 [K]
    rh::Float64             # 相対湿度 [-]（0〜1）
    vol::Float64            # 体積 [m³]
    H_in, H_wall, H_vent    # 熱流入源（発熱源、壁体、換気）[W]
    J_in, J_wall, J_vent    # 水分流入源 [kg/s]
end
```

**主要関数**:
- `convertRH2Pv`: 相対湿度 → 水蒸気圧
- `convertRH2Miu`: 相対湿度 → 水分化学ポテンシャル
- `convertPv2AH`: 水蒸気圧 → 絶対湿度

---

### 2. Cell（cell.jl）- 壁体セル

壁体内の各セル（微小体積要素）の状態を表現します。

```julia
struct Cell
    material_name::String           # 材料名
    temp::Float64                   # 温度 [K]
    miu::Float64                    # 水分化学ポテンシャル [J/kg]
    dx, dy, dz::Float64             # セル寸法 [m]
    dx2::Float64                    # 質点から端までの距離 [m]
    Q::Array{Array{Float64,1},1}    # 熱流量：[[流入X,Y,Z], [流出X,Y,Z]]
    Jv::Array{Array{Float64,1},1}   # 水蒸気流量 [kg/s]
    Jl::Array{Array{Float64,1},1}   # 液水流量 [kg/s]
end
```

**物性値アクセス関数**:
```julia
lam(cell)    # 熱伝導率 [W/(m·K)]
dp(cell)     # 湿気伝導率 [kg/(m·s·Pa)]
dw(cell)     # 液水伝導率 [kg/(m·s)]
ldmg(cell)   # 水分化学ポテンシャル勾配係数
ldtg(cell)   # 温度勾配係数
phi(cell)    # 含水率 [kg/m³]
```

### 3. Wall（wall.jl）- 壁体

壁体全体の構成と特性を管理します。

```julia
struct Wall
    num::Int                        # 壁番号
    name::String
    IP, IM::Int                     # 接続する室番号（0で外気）
    ION::Float64                    # 傾斜角 [°]
    thickness, area::Float64        # 厚さ・面積
    cell[]::Array{Cell}             # セル配列
    target_model[]                  # [BC_IP, Cell1, Cell2, ..., BC_IM]
    BC_IP, BC_IM                    # 境界条件
end
```

- `IP`: 上流側（外気側）の室番号
- `IM`: 下流側（内室側）の室番号
- `target_model`: 計算時に使用する配列（境界条件 + セル群 + 境界条件）

### 7. BoundaryCondition（boundary_condition.jl）- 境界条件

# 3種類の境界条件

### 2. transfer_in_media.jl - 熱・水分移動計算（45KB）

最大のモジュールで、熱・水分移動の計算式と支配方程式を実装します。

#### 熱移動関数
```julia
cal_q(cell_mns, cell_pls)           # セル間熱流束 [W/m²]
                                     # フーリエの法則: q = -λ(∂T/∂x)

cal_heat_transfer_diff(α, T_mns, T_pls)  # 熱伝達流束 [W/m²]
```

#### 水蒸気移動関数
```julia
cal_jv(cell_mns, cell_pls)          # セル間水蒸気流束 [kg/(m²·s)]
                                     # フィックの法則: jv = -δp(∂pv/∂x)
```

#### 液水移動関数
```julia
cal_jl(cell_mns, cell_pls, sin_angle)  # 液水流束 [kg/(m²·s)]
                                       # 毛管圧勾配 + 重力
```

#### 新値計算関数
```julia
cal_newtemp(cell, Q_sum, Jv_sum, dt)   # 新温度
cal_newmiu(cell, Jv_sum, Jl_sum, dt)   # 新水分化学ポテンシャル
cal_newRH(air, dt)                      # 室の新相対湿度
```

### 3. flux_ventilation.jl - 換気流量計算

換気に伴う熱・水分流量を計算します。

```julia
# 熱流量 [W]
H_vent = Qv * ρ * ca * (T_IM - T_IP)

# 水分流量 [kg/s]
J_vent = Qv * ρ * (ah_IM - ah_IP)
```

## 補助関数モジュール

### function/vapour.jl - 水蒸気圧変換

```julia
# 飽和水蒸気圧（Magnus式）
Pvs(T) = 611.2 * exp(17.62 * (T-273.15) / (243.12 + T-273.15))

# 相対湿度 → 水蒸気圧
Pv(T, rh) = Pvs(T) * rh

# 水蒸気圧 → 絶対湿度
AH(Pv, T) = 0.622 * Pv / (P_atm - Pv)
```

## Logger（logger.jl）

結果のCSV出力を管理します。

```julia
mutable struct Logger
    file::Array{IOStream,1}         # ファイルハンドル
    file_name::String
    logging_interval::Float64       # 出力間隔 [hour]
    data_type::Array{String,1}      # ["temp","rh","ah","phi"]
    logging_data::Any               # ロギング対象データ
end
```

**出力対象**:
1. result_all_rooms: 全室の温度・湿度
2. result_wall*: 壁体内の温湿度分布
3. result_room_analysis: 熱収支・水分収支詳細
