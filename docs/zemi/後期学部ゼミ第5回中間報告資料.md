## 3. FFT解析パイプラインの構築

### 3.1. 本章の目的

前回までに、Juliaシミュレーションによって75パターン（5壁構造 × 5換気量 × 3気候）の室内温湿度時系列データを生成した。本章では、これらの時系列データから**建物性能の情報を抽出するためのFFT解析パイプライン**を構築する。

### 3.2. なぜFFT解析を行うのか

#### 理論的背景

建物の温湿度応答は、外気温湿度の周期的な変動（日周期・年周期など）に対する**周波数応答**として捉えることができる。第3章で示したように、室内湿度の伝達関数は以下の式で表される：

$$
\left|\frac{X_r}{X_0}\right|^2 = f(n, S, \lambda', a', \omega)
$$

この式が示すように、振幅減衰率は**換気量 n**、**壁面積 S**、**材料物性（λ', a'）**、**周波数 ω** の関数として決まる。したがって、周波数ごとの応答特性を調べることで、これらの建物性能パラメータに関する情報を抽出できる可能性がある。

#### 周波数帯ごとに現れる建物性能の違い

| 周波数帯 | 周期 | 主に現れる建物性能 |
|---------|------|-------------------|
| 高周波 | 日周期（1日） | 壁体の蓄熱性能、断熱性能 |
| 中周波 | 週〜月周期 | 換気量、気密性 |
| 低周波 | 年周期 | 断熱性能、熱容量 |
| 湿度応答 | 全周波数帯 | 吸放湿性能、換気量 |

これらの周波数成分の**振幅**と**位相**を特徴量として抽出し、機械学習モデルの入力とすることで、建物性能の逆推定を行う。

### 3.4. 各ステップの詳細

#### Step 2: FFT-all.py（生FFT解析）

**目的**：時間領域の温湿度データを周波数領域に変換する

**入力データ形式**：
```csv
,room1,room1,room1,room2,room2,room2,
,temp,rh,ah,temp,rh,ah,
2022/04/01 00:00,15.2,0.65,0.00698,25.0,0.5,0.00988,
2022/04/01 01:00,14.8,0.67,0.00712,...
```
- room1 = 外気（outdoor）
- room2 = 室内（indoor）

**処理内容**：
1. 時系列データに対してFFT（高速フーリエ変換）を適用
2. 各周波数成分の振幅と位相を算出
3. 周波数を周期（日数）に変換

**出力**：
- `spectrum_room2_temp.csv`：室内温度のスペクトル
- `spectrum_room2_rh.csv`：室内相対湿度のスペクトル
- 各ファイルは数千行（周波数分解能に応じた連続スペクトル）

#### Step 3: FFT-binning.py（周波数ビニング）

**目的**：連続スペクトルを離散的な周期バンドに集約し、特徴量として扱いやすくする

**なぜビニングが必要か**：
- 生FFTの出力は数千行 → 機械学習の入力としては次元が高すぎる
- 物理的に意味のある周期帯（日周期、週周期など）で集約したい
- ノイズの影響を低減したい

**周期バンドの設定**：
| バンド | 周期範囲 | 代表的な現象 |
|--------|---------|-------------|
| 0.1日 | 0〜0.15日 | 高周波ノイズ |
| 0.2日 | 0.15〜0.35日 | 半日周期 |
| 0.5日 | 0.35〜0.75日 | 半日周期 |
| 1.0日 | 0.75〜1.5日 | **日周期**（重要） |
| 2.0日 | 1.5〜4.5日 | 数日周期 |
| 7.0日 | 4.5〜10.5日 | **週周期** |
| 14.0日 | 10.5〜22日 | 2週間周期 |
| 30.0日 | 22〜60日 | **月周期** |
| 90.0日 | 60〜227日 | 季節周期 |
| 365.0日 | 227日以上 | **年周期**（重要） |

**処理内容**：
1. 各周期バンドに含まれる周波数成分を抽出
2. 振幅は算術平均を計算
3. 位相は円周平均（circular mean）を計算

**出力**：10行程度のビニング済みスペクトル

#### Step 4: FFT-integrate.py（統合CSV作成）

**目的**：全75パターンの結果を1つのファイルに統合し、比較・考察しやすくする

**出力形式**：
```csv
period_days, w01-base_o01-base_kyoto, w01-base_o02-low_kyoto, ...
0.1,          0.0003,                  0.0003,                ...
1.0,          0.0246,                  0.0265,                ...  ← 日周期
30.0,         0.1381,                  0.1377,                ...  ← 月周期
```
- 行：周期（日数）
- 列：各パターン（壁構造_換気量_気候）

**出力ファイル**：
| ファイル名 | 内容 |
|-----------|------|
| spectrum_room2_temp_amplitude.csv | 室内温度の振幅 |
| spectrum_room2_temp_phase.csv | 室内温度の位相 |
| spectrum_room2_rh_amplitude.csv | 室内湿度の振幅 |
| spectrum_room2_rh_phase.csv | 室内湿度の位相 |
| all_spectrums.xlsx | 上記を1つのExcelに統合 |

### 3.5. 期待される結果と考察の方向性

#### 温度応答から読み取れる情報
- **日周期の振幅差**：蓄熱性能の違い（RC単層 vs 断熱構造）
- **位相の遅れ**：熱容量の大きさ（外断熱 vs 内断熱の違い）

#### 湿度応答から読み取れる情報
- **換気量による振幅差**：換気量が大きいほど外気に追従 → 振幅大
- **吸放湿性能の影響**：土壁や調湿材は湿度変動を緩和 → 振幅小

#### 機械学習への活用
- 10周期 × 4種類（温度振幅・温度位相・湿度振幅・湿度位相）= **40次元の特徴量ベクトル**
- これを入力として、壁構造・換気量の分類モデルを構築

### 3.6. 現状の課題：気候条件への依存性

現在の特徴量（室内温湿度の絶対的な振幅・位相）には問題がある。

**問題点**：
```
京都の外気 → 京都の室内応答  ┐
                              ├→ 外気条件が異なるため単純比較できない
沖縄の外気 → 沖縄の室内応答  ┘
```

同じ建物性能でも、外気条件（気温・湿度の年較差など）が異なれば、室内の絶対的な振幅・位相は異なってしまう。これでは「京都で学習したモデルが沖縄で使えない」という汎化性能の問題が生じる。

### 3.7. 解決策：室内/室外の相対的な応答を特徴量とする

**解決策**：室内の絶対値ではなく、**室内/室外の比（伝達関数）** を特徴量として使用する。

$$
\text{振幅比} = \frac{|X_{\text{室内}}(\omega)|}{|X_{\text{外気}}(\omega)|}
$$

$$
\text{位相差} = \phi_{\text{室内}}(\omega) - \phi_{\text{外気}}(\omega)
$$

**この方法のメリット**：
- 振幅比・位相差は**外気条件によらず、建物固有の性能のみを反映**する
- 理論的にも、第3章で示した伝達関数 $X_r/X_0$ に対応する
- 京都で学習したモデルが沖縄・札幌でも適用可能になる（はず）

**イメージ図**：
```
┌─────────────────────────────────────────────────────────────┐
│  従来の特徴量（絶対値）                                      │
│                                                             │
│  京都: 室内振幅 = 0.05  ─┐                                  │
│  沖縄: 室内振幅 = 0.08  ─┼→ 気候によって値が異なる          │
│  札幌: 室内振幅 = 0.03  ─┘   → 比較困難                     │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  新しい特徴量（相対値）                                      │
│                                                             │
│  京都: 室内/外気 = 0.7  ─┐                                  │
│  沖縄: 室内/外気 = 0.7  ─┼→ 同じ建物なら同じ値になる        │
│  札幌: 室内/外気 = 0.7  ─┘   → 気候によらず比較可能         │
└─────────────────────────────────────────────────────────────┘
```
