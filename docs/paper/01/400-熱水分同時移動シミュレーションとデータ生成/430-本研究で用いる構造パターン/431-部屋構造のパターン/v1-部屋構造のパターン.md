### 部屋構造のパターン

　本研究では、建物性能の逆推定に必要な学習データを生成するため、単純化された単室モデルを採用する。これは、壁構造や換気量の影響を明確に抽出するためであり、複数室間の熱・水分移動による複雑な相互作用を排除する意図がある。

#### 単室モデルの構成

　本研究で使用する部屋構造の諸元を表4.3.1に示す。

**表4.3.1　部屋構造の設定**

| 項目 | 設定値 | 備考 |
|------|--------|------|
| 室容積 | 62.5 m³ | 床面積25 m²×天井高2.5 m相当 |
| 壁面積 | 100 m² | 6面（天井・床・4側壁）の合計 |
| 初期室温 | 25℃ | - |
| 初期相対湿度 | 50% | - |
| 室内発熱量 | 0 W | 自然室温条件 |
| 室内発湿量 | 0 kg/s | 自然湿度条件 |

　室容積62.5 m³は、日本の住宅における標準的な居室サイズ（約7.6坪）を想定した値である。

#### 内部発熱・発湿を0とした理由

　本研究では、壁構造と換気量が室内環境に与える影響を純粋に評価するため、室内発熱量および室内発湿量をいずれも0に設定している。これにより、室内温湿度の変動は以下の要因のみに起因することになる。

1. 外気温湿度の変動（気象データによる外乱）
2. 壁体を介した熱・水分の伝導・蓄熱・調湿
3. 換気による熱・水分の輸送

　実際の建物では居住者の在室や家電機器による発熱・発湿が存在するが、これらは時刻や生活パターンによって大きく変動する。本研究の目的である建物固有の性能評価においては、このような変動要因を排除し、自然室温・自然湿度条件下での応答を分析することで、建物そのものが持つ熱的・湿気的特性を明確に捉えることができる。

#### 部屋構造を固定とした理由

　本研究では部屋構造を1パターンに固定し、壁構造と換気量のみをパラメータとして変化させる。これは以下の理由による。

　第一に、室容積が変わると熱容量・換気回数等が同時に変化し、壁構造・換気量の影響と分離することが困難になる。第二に、パラメータ空間を限定することで必要な計算ケース数を抑制し、効率的なデータ生成が可能となる。第三に、周波数応答特性の違いを壁構造・換気量の差異に帰属させやすくなり、逆推定モデルの解釈性が向上する。

　将来的には、室容積や形状をパラメータに加えることで、より汎用的な逆推定手法への拡張が期待される。
