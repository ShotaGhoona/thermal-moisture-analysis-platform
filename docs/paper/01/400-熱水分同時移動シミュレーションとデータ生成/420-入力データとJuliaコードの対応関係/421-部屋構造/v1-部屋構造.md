### 部屋構造

　本シミュレーションにおける室空間は、完全混合を仮定した空気塊としてモデル化される。室内空気は均一な温度・湿度を持ち、壁体表面および開口部を介して外気と熱・水分を交換する。

#### 室空間の定義パラメータ

　室空間を定義するために必要なパラメータを表4.2.1に示す。

**表4.2.1　室空間の定義パラメータ**

| パラメータ | 単位 | 説明 |
|------------|------|------|
| 室番号 | - | 室の識別番号 |
| 室名 | - | 室の名称 |
| 容積 | m³ | 室の体積 |
| 初期温度 | ℃ | 計算開始時の室温 |
| 初期相対湿度 | % | 計算開始時の相対湿度 |
| 床面高さ | m | 基準面からの床面の高さ |
| 発熱量 | W | 室内における顕熱発生量 |
| 発湿量 | kg/s | 室内における水分発生量 |

　室番号は、壁体や開口部の接続先を指定する際の識別子として用いられる。本シミュレーションでは室番号1を外気として扱い、外界気象データと連動させる。室番号2以降が実際の解析対象となる室空間である。

#### 室空気の熱・水分収支

　室空気の温度および湿度は、各時間ステップにおいて以下の収支式に基づいて更新される。

**熱収支式：**

$$T_{new} = T + \frac{H_{wall} + H_{vent} + H_{in}}{\rho c_a V / \Delta t}$$

**水分収支式：**

$$x_{new} = x + \frac{J_{wall} + J_{vent} + J_{in}}{\rho V / \Delta t}$$

　ここで、$T$は室温[K]、$x$は絶対湿度[kg/kg']、$H_{wall}$は壁体表面からの熱流入量[W]、$H_{vent}$は換気による熱流入量[W]、$H_{in}$は室内発熱量[W]、$J_{wall}$は壁体表面からの水分流入量[kg/s]、$J_{vent}$は換気による水分流入量[kg/s]、$J_{in}$は室内発湿量[kg/s]である。また、$\rho$は空気密度[kg/m³]、$c_a$は湿り空気の比熱[J/(kg·K)]、$V$は室容積[m³]、$\Delta t$は時間刻み[s]を表す。

　この収支式により、壁体を介した熱・水分移動と換気による熱・水分輸送の両方を考慮した室内環境の時間変化を追跡することができる。
