### 壁構造

　壁体は室内空気と外気を隔てる境界として、熱・水分の伝導および蓄熱・調湿の役割を担う。本シミュレーションでは壁体を厚さ方向に有限個のセルに分割し、各セルにおける温度・水分化学ポテンシャルの時間変化を追跡する一次元非定常解析を行う。

#### 壁体の定義パラメータ

　壁体全体を定義するための主要なパラメータを表4.2.3に示す。

**表4.2.3　壁体の定義パラメータ**

| パラメータ | 単位 | 説明 |
|------------|------|------|
| 壁番号 | - | 壁体の識別番号 |
| 外気側室番号 | - | 外気側に接する室の番号 |
| 室内側室番号 | - | 室内側に接する室の番号 |
| 壁の厚み | m | 壁体の総厚 |
| 壁の面積 | m² | 壁体の表面積 |
| 壁の傾斜角 | 度 | 水平面に対する角度（0：水平、90：垂直） |
| 外気側対流熱伝達率 | W/(m²·K) | 外気側表面の対流熱伝達率 |
| 室内側対流熱伝達率 | W/(m²·K) | 室内側表面の対流熱伝達率 |
| 外気側輻射熱伝達率 | W/(m²·K) | 外気側表面の輻射熱伝達率 |
| 室内側輻射熱伝達率 | W/(m²·K) | 室内側表面の輻射熱伝達率 |

　外気側室番号に1を指定することで、壁体が外気に面していることを表す。

#### 壁体内部の層構成

　壁体内部の層構成は、各セルの材料名・厚み・初期条件によって定義される。セルごとに異なる材料を指定することで、複数材料から構成される複合壁体を表現できる。各セルに必要なパラメータを表4.2.4に示す。

**表4.2.4　セルの定義パラメータ**

| パラメータ | 単位 | 説明 |
|------------|------|------|
| セル番号 | - | 外気側から順に1, 2, 3, ... |
| セル幅 | m | 厚さ方向のセル幅 |
| 材料名 | - | セルを構成する材料 |
| 初期温度 | ℃ | 計算開始時の温度 |
| 初期相対湿度 | % | 計算開始時の相対湿度 |

　各材料の熱伝導率・湿気伝導率・水分特性曲線などの物性値は、材料ごとに別途定義されている。

#### 壁体表面の境界条件

　壁体表面では第三種境界条件（Robin条件）を適用し、室空気または外気との熱・水分交換を計算する。総合熱伝達率$\alpha$は対流熱伝達率$\alpha_c$と輻射熱伝達率$\alpha_r$の和として定義される。

$$\alpha = \alpha_c + \alpha_r$$

　湿気伝達率はLewis関係式に基づき、対流熱伝達率から算出される。

#### 壁体内の熱・水分移動

　隣接セル間および境界面での熱・水分流束は、以下の式に基づいて計算される。

**熱伝導（フーリエの法則）：**

$$q = -\lambda \frac{\partial T}{\partial x}$$

**水蒸気拡散（フィックの法則）：**

$$j_v = -\delta_p \frac{\partial p_v}{\partial x}$$

**液水移動：**

$$j_l = -\lambda'_{\mu l} \left( \frac{\partial \mu}{\partial x} + g \cdot \sin\theta \right)$$

　ここで、$\lambda$は熱伝導率[W/(m·K)]、$\delta_p$は湿気伝導率[kg/(m·s·Pa)]、$\lambda'_{\mu l}$は液水伝導率[kg/(m·s·(J/kg))]、$p_v$は水蒸気圧[Pa]、$\mu$は水分化学ポテンシャル[J/kg]、$g$は重力加速度[m/s²]、$\theta$は壁の傾斜角[rad]である。

　壁体表面での熱・水分流束は、それぞれ接続する室の熱収支・水分収支に積算される。
