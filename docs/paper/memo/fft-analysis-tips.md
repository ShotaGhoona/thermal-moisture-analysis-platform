# FFT解析結果から考察を発見するためのガイドライン

## 1. これまでの4事例の振り返り

### 事例1: 短周期における換気量の影響の消失（温度）
- **発見**: 短周期で換気量によらず地域ごとにグループ化
- **着眼点**: 「なぜ換気量の影響が見えないのか？」
- **物理的説明**: 換気による熱交換（6〜24 W/K）vs 壁体表面との熱交換（930 W/K）→ 1〜3%
- **教訓**: 定量的な比較が説得力を持つ
- **最初の誤り**: 「長周期では換気量の差が出る」と書いたが、実際は1に収束して差がなくなっていた。グラフを再確認して修正した。

### 事例2: 絶対湿度振幅比における換気量の明確な影響
- **発見**: 全周期帯で換気量順に分離（強換気が上、無換気が下）
- **着眼点**: 事例1との対比（温度では見えなかった換気量の影響が湿度では見える）
- **物理的説明**: 壁体の吸放湿性が低い→換気の相対的寄与が大きい
- **教訓**: 異なる物理量（温度 vs 湿度）を比較すると新しい知見が得られる
- **ユーザーの示唆**: 「換気量を抑えることが絶対湿度の振幅を抑えている」という見方を示された

### 事例3: 無換気条件における土壁の特異な相対湿度応答
- **発見**: 土壁だけが振幅比1を超える（他は0.2以下）
- **着眼点**: 「なぜ土壁だけが跳ね上がるのか？」
- **物理的説明**: 温度駆動の吸放湿（温度変化→飽和水蒸気圧変化→壁が吸放湿→絶対湿度変動）
- **教訓**: 特定の条件（無換気）で特異な挙動を示す材料に注目
- **用語の修正**: 「壁体との水蒸気交換」→「壁体の吸放湿」に修正。正確な用語を使うことの重要性。

### 事例4: 無換気条件における温度振幅比と壁体熱容量の関係
- **発見**: 土壁が上（0.5〜0.6）、RC内断熱+調湿が下（0.2〜0.35）
- **着眼点**: 「壁構造による差は何で説明できるか？」
- **物理的説明**: 熱容量の違い（土壁≈10万 J/(m²·K)、RC≈31万 J/(m²·K)）
- **教訓**: 物性値から定量的に説明できると説得力がある
- **ユーザーの示唆**: 「RC内断熱+調湿は壁厚が大きいからでは？」という仮説から出発

## 2. グラフを見る時の「目の動かし方」

### 2.1 最初に全体像を把握する
1. **線が何本あるか確認する**: 凡例を見て、何が比較されているか理解する
2. **Y軸のスケールを確認する**: 振幅比なら0〜1.5程度、位相差なら-π〜π程度
3. **X軸の範囲を確認する**: 0.1日〜365日の対数スケール

### 2.2 パターンを探す
1. **グループ化を探す**: 複数の線が束になっている箇所はないか？
   - 例: 事例1で短周期側で地域ごとにグループ化
   - 意味: 何かが支配的で、他のパラメータの影響が消えている

2. **分離を探す**: 線が順序よく並んでいる箇所はないか？
   - 例: 事例2で換気量順に分離
   - 意味: あるパラメータに明確に依存している

3. **外れ値を探す**: 1本だけ明らかに違う挙動の線はないか？
   - 例: 事例3で土壁だけが跳ね上がる
   - 意味: その材料/条件に固有の物理現象がある

4. **周期帯による変化を探す**: 短周期と長周期で傾向が変わる箇所はないか？
   - 例: 事例1で短周期と長周期で挙動が異なる
   - 意味: 時間スケールによって支配的な物理現象が変わる

5. **特異点を探す**: 振幅比が1を超える、0に近づく、交差するなど
   - 例: 事例3で振幅比が1を超える
   - 意味: 通常とは異なる物理現象が起きている

### 2.3 周期帯の意味を意識する
- **短周期（0.1〜0.5日）**: 壁体内部まで熱/水分が浸透しない。表面現象が支配的。
- **日周期（1日前後）**: 日変動に対する応答。実用上重要な周期帯。
- **週〜月周期（7〜30日）**: 中間的な時間スケール。蓄熱/蓄湿効果が効き始める。
- **長周期（100日以上）**: 季節変動。十分長いので定常状態に近づく。

## 3. 「面白い」と感じる判断基準

### 3.1 予想と違う結果
- 「無換気なのに振幅比が1を超える」（事例3）
- 「換気量を変えても振幅比が変わらない」（事例1の短周期）
- 予想: 換気量が大きいほど外気に追従 → 実際: 短周期では関係ない

### 3.2 特定の条件だけ異なる挙動
- 「土壁だけが跳ね上がる」（事例3, 4）
- 「RC内断熱+調湿だけが下に行く」（事例4）
- 他と違う挙動は、その条件に固有の物理現象を示唆する

### 3.3 パラメータの影響が「見える/見えない」の境界
- 温度では換気量の影響が見えにくいが、絶対湿度では明確（事例1 vs 事例2）
- 「どの物理量で、どの周期帯で、どのパラメータの影響が見えるか」が識別可能性の鍵

### 3.4 論文のストーリーに貢献する発見
- 識別可能性を示す発見: 「この条件でこのパラメータを識別できる」
- 識別困難性を示す発見: 「この条件ではこのパラメータを識別できない」
- 両方が重要。限界を示すことも学術的価値がある。

## 4. 物理的説明を考える時の思考プロセス

### 4.1 「何が支配的か」を考える
- 複数の物理現象が競合している場合、どれが支配的かを考える
- 例: 短周期の温度変動 → 換気 vs 壁体表面熱伝達 → 壁体表面が支配的（930 vs 6〜24）

### 4.2 2つの効果を比較する
- 定量的に比較できると説得力が増す
- 例: 「換気による熱交換は壁体表面との熱交換の1〜3%に過ぎない」
- 比較の仕方: 同じ単位（W/K、J/(m²·K)など）に揃えて比較

### 4.3 時間スケールと空間スケールを意識する
- **熱浸透深さ**: 周期の平方根に比例。短周期では表面近傍のみ、長周期では壁体全体。
- **時定数**: 系が応答するのにかかる時間。周期 << 時定数なら追従できない。
- 例: 短周期では壁体内部まで熱が伝わらないので、壁体の熱容量が効かない

### 4.4 材料特性の違いを思い出す
- **熱的性質**: コンクリート（高蓄熱）、グラスウール（高断熱）、土壁（中程度）
- **湿気的性質**: コンクリート（低吸放湿）、土壁（高吸放湿）
- **カップリング**: 温度変化 → 飽和水蒸気圧変化 → 相対湿度変化 → 吸放湿

### 4.5 極端なケースから考える
- 「もし換気が0だったら？」→ 壁体の吸放湿のみで室内湿度が決まる
- 「もし壁体が完全に断熱材だったら？」→ 熱容量がないので即座に外気に追従
- 極端なケースを想像すると、物理的メカニズムが見えやすい

## 5. 仮説を立てて検証するプロセス

### 5.1 仮説の立て方
1. グラフのパターンを観察する
2. 「なぜこうなるのか？」と問う
3. 物理的なメカニズムを仮説として立てる
4. その仮説が正しければ、他にどんな予測ができるか考える

### 5.2 仮説の検証方法
1. **定量的検証**: 物性値から計算して、仮説と整合するか確認
2. **他のグラフとの整合性**: 同じ仮説で他の現象も説明できるか
3. **極端なケースでの検証**: 仮説が正しければ、極端な条件でどうなるか

### 5.3 仮説が間違っていた場合
- 事例1で「長周期では換気量の差が出る」と仮説を立てたが、グラフを見直すと1に収束していた
- 間違いに気づいたら素直に修正する
- 間違いから学ぶ: 「長周期では全てが外気に追従するので差がなくなる」

## 6. グラフのフィルタ条件の選び方

### 6.1 「何を固定して何を変えるか」が重要
- **換気量を固定して壁構造を比較**: 壁構造の影響を見たい時
- **壁構造を固定して換気量を比較**: 換気量の影響を見たい時
- **物理量を変えて比較**: 温度 vs 相対湿度 vs 絶対湿度

### 6.2 極端な条件で見ると差が明確になる
- **無換気（o04）**: 換気の影響を排除して壁体の効果のみを見る
- **土壁（w05）**: 吸放湿性が最も高い材料の挙動を見る
- 極端な条件では、通常見えない効果が顕在化する

### 6.3 比較のための「対照群」を意識する
- 事例2: 温度（事例1）と絶対湿度を比較 → 換気量の影響の違いが明確に
- 事例3: RC壁と土壁を比較 → 土壁の特異性が明確に
- 「何と比較しているか」を意識すると、発見の意味が明確になる

### 6.4 未探索の有望なパターン
```
換気量固定:
- [ ] ratio_temp@o01, o02, o03（無換気以外）
- [ ] ratio_ah@o04（無換気・絶対湿度）→ 土壁の吸放湿が見える？

壁構造固定:
- [ ] ratio_temp@w05（土壁のみ）→ 換気量の影響は？
- [ ] ratio_rh@w05（土壁・相対湿度）

地域比較:
- [ ] 同じ壁構造・換気量で3地域を比較 → 振幅比の頑健性確認

位相差:
- [ ] diff_temp, diff_rh, diff_ah → まだ全く見ていない
```

## 7. 考察の「深さ」の判断

### 7.1 レベル1: 現象の記述（不十分）
- 「土壁の振幅比が高い」
- これだけでは考察ではなく、単なる観察

### 7.2 レベル2: 定性的な説明（最低限）
- 「土壁は熱容量が小さいので、振幅比が高くなる」
- 理由が述べられているが、定量性がない

### 7.3 レベル3: 定量的な説明（良い）
- 「土壁の熱容量は約10万J/(m²·K)、RC単層は約31万J/(m²·K)であり、土壁は約1/3である。そのため熱を蓄えにくく、振幅比が高くなる」
- 数値で裏付けられている

### 7.4 レベル4: 識別可能性への示唆（完成）
- 上記に加えて「したがって、無換気条件下の温度振幅比から、土壁とRC壁を識別できる可能性がある」
- 本研究の目的（逆推定）に結びついている

## 8. 文章を書く時の判断

### 8.1 構成の順番
1. **図の提示**: 「図7.Xに〇〇を示す」
2. **現象の説明**: グラフから読み取れる事実
3. **物理的メカニズム**: なぜそうなるのか
4. **定量的検証**: 可能であれば数値で裏付け
5. **識別可能性への示唆**: 本研究の目的との関連

### 8.2 前の事例との対比を入れる
- 「これは前節で示した温度振幅比の結果と対照的である」（事例2）
- 対比があると、発見の意味が明確になる
- 読者にとっても理解しやすい

### 8.3 用語の正確さ
- 「壁体との水蒸気交換」→「壁体の吸放湿」
- 専門用語は正確に使う
- 曖昧な表現は避ける

### 8.4 図番号の管理
- 7章の図は「図7.1」「図7.2」...と連番
- 複数のサブ図がある場合は「図7.2a」「図7.2b」

## 9. よくある誤りとその対処

### 9.1 グラフの読み間違い
- **誤り**: 長周期で差が出ると思ったら、実は1に収束して差がなくなっていた
- **対処**: グラフを書いた後、もう一度よく見る。特に端の方（短周期、長周期）

### 9.2 因果関係の逆転
- **誤り**: 「振幅比が大きいから熱容量が小さい」（逆）
- **正しい**: 「熱容量が小さいから振幅比が大きい」
- **対処**: 物理的な因果の方向を意識する

### 9.3 過度な一般化
- **誤り**: 「土壁は常に振幅比が高い」
- **正しい**: 「無換気条件下の短周期〜日周期帯において、土壁の温度振幅比が高い」
- **対処**: どの条件で、どの周期帯で、という限定を付ける

### 9.4 物理的説明の欠如
- **誤り**: 現象を述べるだけで「なぜ」がない
- **対処**: 必ず「これは〇〇から説明できる」という文を入れる
