# 円周平均（Circular Mean）の解説

## なぜ普通の平均ではダメなのか？

### 位相は「角度」である

位相 $\phi$ は $-\pi$ から $\pi$（-180° から +180°）の範囲で表される**角度**です。
角度は**円周上の位置**を表すので、$-\pi$ と $\pi$ は実は**同じ位置**です。

```
            90° (π/2)
              |
              |
  180° ------●------ 0°
  (-π)        |      (0)
              |
           -90° (-π/2)

※ 180°と-180°は同じ点！
```

### 算術平均の問題

**例1：位相が -170° と +170° の場合**

```
算術平均：(-170° + 170°) / 2 = 0°
```

しかし、円周上で考えると：

```
        90°
         |
  -170°  ●  170°
    ↖   |   ↗
      ↖ | ↗
  180° --●-- 0°    ← 両方とも180°の近く！
```

直感的には、平均は**180°付近**にあるべきです。0°は全く逆の方向です。

**例2：位相が -π と +π の場合**

```
算術平均：(-π + π) / 2 = 0
```

しかし、$-\pi$ と $\pi$ は**完全に同じ点**なので、平均も $\pm\pi$ であるべきです！

---

## 円周平均の考え方

### ステップ1：角度をベクトルに変換

角度 $\phi$ を、単位円上の点（ベクトル）として表現します：

$$
\phi \quad \rightarrow \quad (\cos\phi, \sin\phi)
$$

```
例：φ = 60°の場合

        ●  ← (cos60°, sin60°) = (0.5, 0.87)
       /|
      / |
     /  |
    ●---+--- 0°
```

### ステップ2：ベクトルを足し合わせる

複数の角度がある場合、それぞれのベクトルを足し合わせます：

$$
\text{合成ベクトル} = \left( \sum_k \cos\phi_k, \sum_k \sin\phi_k \right)
$$

### ステップ3：合成ベクトルの角度を求める

足し合わせたベクトルの方向が「円周平均」です：

$$
\bar{\phi} = \arctan\left( \frac{\sum_k \sin\phi_k}{\sum_k \cos\phi_k} \right)
$$

---

## 具体例で理解する

### 例1：-170° と +170° の円周平均

**ステップ1：ベクトルに変換**
```
-170° → (cos(-170°), sin(-170°)) = (-0.985, -0.174)
+170° → (cos(+170°), sin(+170°)) = (-0.985, +0.174)
```

**ステップ2：ベクトルを足す**
```
合成 = (-0.985 + (-0.985), -0.174 + 0.174)
     = (-1.970, 0)
```

**ステップ3：角度を求める**
```
arctan(0 / -1.970) = 180° (または -180°)
```

→ **正解！** 180°付近が平均として得られました。

### 例2：0° と 90° の円周平均

**ステップ1：ベクトルに変換**
```
  0° → (1, 0)
 90° → (0, 1)
```

**ステップ2：ベクトルを足す**
```
合成 = (1, 1)
```

**ステップ3：角度を求める**
```
arctan(1 / 1) = 45°
```

→ **正解！** 0°と90°の中間である45°が得られました。

### 視覚的なイメージ

```
        90°
         ● ← 90°のベクトル
        /|
       / |
    45°← ● 合成ベクトル（平均の方向）
     /   |
    /    |
   ●-----●---- 0° ← 0°のベクトル
```

## なぜこれで上手くいくのか？

### 重心の考え方

円周平均は、単位円上に配置された点の**重心**の方向を求めていることと同じです。

```
複数の点が円周上にある場合：

        ●
       / \
      /   \
     ●     ●
      \   /
       \ /
        ★ ← 重心（この方向が円周平均）
```

点が一箇所に集まっていれば、重心もその方向を向きます。
点が散らばっていれば、重心は中心に近づきます（平均の信頼度が下がる）。

### 算術平均との比較

| 状況 | 算術平均 | 円周平均 |
|-----|---------|---------|
| 30° と 60° | 45° | 45° |
| -10° と +10° | 0° | 0° |
| -170° と +170° | **0°** (誤り) | **180°** (正解) |
| -π と +π | **0** (誤り) | **±π** (正解) |

近い角度同士では両者は一致しますが、**180°をまたぐ**場合に差が出ます。

## Pythonでの実装

```python
import numpy as np

def circular_mean(phases):
    """
    位相（ラジアン）の円周平均を計算

    Parameters
    ----------
    phases : array-like
        位相の配列 [rad]

    Returns
    -------
    float
        円周平均 [rad]、範囲は -π から π
    """
    sin_sum = np.sum(np.sin(phases))
    cos_sum = np.sum(np.cos(phases))
    return np.arctan2(sin_sum, cos_sum)


# 使用例
phases = np.array([-170, 170]) * np.pi / 180  # 度をラジアンに変換
mean_phase = circular_mean(phases)
print(f"円周平均: {mean_phase * 180 / np.pi:.1f}°")  # 180.0°
```

### なぜ `arctan2` を使うのか？

通常の `arctan` は $-\pi/2$ から $\pi/2$ の範囲しか返しません。
`arctan2(y, x)` は**象限を正しく判定**して、$-\pi$ から $\pi$ の全範囲を返します。

```python
import numpy as np

# arctan vs arctan2 の違い
x, y = -1, -1  # 第3象限の点

print(np.arctan(y/x) * 180/np.pi)   # 45°  (誤り：第1象限と誤認)
print(np.arctan2(y, x) * 180/np.pi) # -135° (正解：第3象限)
```

## FFT解析での応用

### 周波数ビニングにおける位相の集約

FFT解析では、連続スペクトルを離散的な周期バンドに集約します。
各バンドに含まれる複数の周波数成分の位相を平均する際に、円周平均を使用します。

```python
def bin_phases(phases, freq_indices):
    """
    周期バンドに含まれる位相を円周平均で集約

    Parameters
    ----------
    phases : array
        全周波数の位相 [rad]
    freq_indices : array
        当該バンドに含まれる周波数インデックス

    Returns
    -------
    float
        集約された位相 [rad]
    """
    band_phases = phases[freq_indices]
    return circular_mean(band_phases)
```

### 位相差の計算

室内と外気の位相差を計算する際も、結果が $-\pi$ から $\pi$ の範囲に収まるよう注意が必要です：

```python
def phase_difference(phase_indoor, phase_outdoor):
    """
    位相差を計算（-π から π の範囲に正規化）
    """
    diff = phase_indoor - phase_outdoor
    # -π から π の範囲に正規化
    return np.arctan2(np.sin(diff), np.cos(diff))
```

## まとめ

| 項目 | 内容 |
|-----|------|
| **問題** | 位相は周期的な量なので、算術平均では180°をまたぐ場合に誤った結果になる |
| **解決策** | 円周平均：角度をベクトルに変換 → 足し合わせ → 合成ベクトルの角度を取る |
| **数式** | $\bar{\phi} = \arctan2\left(\sum \sin\phi_k, \sum \cos\phi_k\right)$ |
| **直感** | 単位円上に配置された点の重心の方向を求める |
| **実装** | `np.arctan2(np.sum(np.sin(phases)), np.sum(np.cos(phases)))` |
