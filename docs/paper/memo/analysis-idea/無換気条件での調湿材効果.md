# 無換気条件での調湿材効果

## 観察したグラフ
- グラフファイル名: `ratio_ah_o04.png`
- フィルタ条件: o04（無換気）、全壁構造・全気候

## 発見した現象

無換気条件（o04）における絶対湿度振幅比は、壁構造によって明確に異なる挙動を示す。

### 壁構造別の特徴
1. **土壁**（ピンク・グレー）: 全周期で高い振幅比（0.6〜1.0）
2. **RC内断熱+調湿**（紫・茶）: 土壁に次いで高い（0.4〜0.7）
3. **RC単層・RC内断熱**（青・緑・橙・赤）: 短周期で低い振幅比（0.1〜0.3）

### 周期依存性
- 短周期（0.1〜0.5日）: 壁構造間の差が最大
- 長周期（30日以降）: 全体的に収束傾向だが、差は残る

## 物理的解釈

無換気条件では、室内湿度変動は壁体の吸放湿のみで緩和される。

1. **土壁**: 高い吸放湿容量により、外気の湿度変動を室内に伝達しやすい（壁体が湿度バッファとして機能し、急激な変化を平滑化しつつも追従）
2. **RC+調湿材**: 調湿ボード層が同様の効果を発揮するが、厚さが薄いため効果は限定的
3. **RC単層**: 吸放湿がほとんどないため、室内湿度は壁体に依存せず外気から切り離される（振幅比が低い）

### 補足: 振幅比の解釈
- 振幅比が高い = 室内が外気に追従しやすい（調湿材による湿度輸送）
- 振幅比が低い = 室内が外気から隔離される（非調湿材）

これは温度の場合と逆の直感になる点に注意。温度では断熱性能が高いほど振幅比が低い（遮断）だが、湿度では調湿性能が高いほど振幅比が高い（追従）。

## 識別可能性への示唆

### 無換気条件の利点
- 換気の影響を排除することで、壁体の調湿性能を純粋に評価できる
- 土壁とRC系の識別が容易

### 実用上の課題
- 完全な無換気状態は現実的でない
- 換気がある場合、調湿効果と換気効果の分離が困難
