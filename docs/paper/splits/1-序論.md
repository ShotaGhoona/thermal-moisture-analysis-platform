# 序論

## 研究の背景

　建築分野では、すでに建てられた既存建物の性能をどう把握し、どのように改修していくのかが大きな課題となっている。断熱性の換気性能などの「建物性能」は、室内性能の快適性やエネルギー消費を左右する重要な要素だが、現状では専門家による調査や詳細なシミュレーションを行わないと正確な評価が難しい。

　建築環境工学の分野では、これまで「建物性能→室内外の温湿度応答」を求める順問題の解析が中心に発展してきた。一方で、「取得した温度・湿度のデータ→建物性能」を逆算する逆問題は理論的に困難とされてきた。特に壁体材料と換気量のように複数のパラメータが同時に効いている場合、それぞれの寄与を分離して推定することは簡単ではない。

　近年は長期間の室温・湿度データを容易に収集できるようになり、これらを用いたデータ駆動型の解析や機械学習の応用が進んでいる。しかし、多くは将来の室温・負荷予測など「予測モデル」としての利用が中心であり、観測データから建物の物理パラメータ（材料、換気量など）を予測する研究はまだ限定的である。

　一方、熱湿気の伝達関数や重み関数を　用いて、外気の変動（年周期・日周期など）に対する室温・室内湿度の「周波数応答」を整理する研究は、鉾井らを中心に進められてきた。これらの研究では、熱水分同時移動方程式を周波数領域で扱い、外乱の周期と壁体・室内の調湿応答の関係を明らかにしている。ここでは室や壁を「ある周波数でのゲインと位相を持つシステム」と捉えて、建物固有の「熱的湿気的な特徴」を議論しているが、それをさらに進めて、測定データから仕様を逆推定するところまでは踏み込んでいない。

　しかし、「自然室温化の温湿度時系列に含まれている周波数成分」には、その建物固有の性能に関する情報が何かしらの形で埋め込まれていると考えられる。もしこの情報をうまく取り出し、機械学習などを組み合わせて逆推定に利用できれば、簡易な温度測定だけで建物性能を評価するという、新しい可能性が開ける。その妥当性や限界を基礎的に研究することが、本研究の背景にある問題意識である。

## 本研究の目的

　本研究の最終的な目標は、自然室温下で測定される室内温湿度データをFFT解析により周波数領域に変換し、その特徴量から建物性能（壁構造・換気量など）を機械学習により逆推定する手法を確立することである。

　この目標に向けて、本研究では以下のステップを設定する。

1. **シミュレーション環境の構築**

　Juliaで実装された熱水分同時移動解析プログラムを用い、壁材料・換気量などをパラメータとして変化させた複数の建物モデルを作成する。各モデルについて外気条件を与えた時の室内温湿度応答を、自然室温（非空調）条件で長期間シミュレーションし、データセットを構築する。

2. **FFT解析による特徴量抽出**

　得られた室内温湿度の時系列データに対してFFT解析を行い、日周期・半日周期・月周期・年周期などの主要周波数ごとの振幅と位相を求める。外気と室内の振幅比・位相差なども特徴量として抽出する。

3. **周波数特徴量と建物性能の対応関係の分析**

　壁構造・換気量の違いが、どの周波数帯の振幅・位相にどのように現れるのかを分析し、周波数特徴量から建物性能を識別できる可能性を検討する。

4. **機械学習による逆推定モデルの構築**（今後の課題）

　上記の周波数特徴量を入力として、壁構造や換気量を出力する機械学習モデル（分類器）を構築し、逆推定の精度と限界を評価する。

　本論文では、上記のステップ1〜3までを実施する。すなわち、シミュレーションによるデータ生成、FFT解析による周波数特徴量の抽出、および周波数特徴量と建物性能の対応関係の分析までを行う。ステップ4の機械学習による逆推定モデルの構築は今後の課題とする。

　卒業論文としての目標は、「周波数特徴量に建物性能の違いがどのように現れるかを明らかにし、どの程度まで性能の違いを識別できる可能性があるのかを検討すること」である。この結果を通じて、将来的に機械学習を用いた逆推定手法を構築するための基礎を築くことを本研究の狙いとする。
