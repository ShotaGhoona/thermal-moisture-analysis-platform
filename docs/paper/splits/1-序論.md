# 序論

## 研究の背景

　建築環境工学において、熱水分同時移動シミュレーションは室内温湿度環境の予測や建物性能の評価に広く用いられている。シミュレーションを行うためには、壁体の材料構成や換気量といった建物の物理パラメータを入力として与える必要がある。

　実際の建物を対象としてシミュレーションを行う場合、入力パラメータが設計図書通りであるとは限らず、また経年変化や施工誤差の影響も存在する。そのため、実測データとシミュレーション結果を比較し、両者の乖離が小さくなるようにパラメータを調整する作業が必要となる。しかし、現状ではこのパラメータ調整は試行錯誤に基づいて行われることが多く、担当者の経験や勘に依存している部分が大きい。壁体材料と換気量のように複数のパラメータが同時に室内環境に影響を与えている場合、それぞれの寄与を分離して適切なパラメータを決定することは容易ではない。

　一方、建築環境工学の分野では、熱湿気の伝達関数や重み関数を用いて、外気の変動（年周期・日周期など）に対する室温・室内湿度の「周波数応答」を整理する研究が、鉾井らを中心に進められてきた。これらの研究では、熱水分同時移動方程式を周波数領域で扱い、外乱の周期と壁体・室内の調湿応答の関係を明らかにしている。室や壁を「ある周波数でのゲインと位相を持つシステム」と捉えることで、建物固有の熱的・湿気的な特徴を議論できることが示されている。

　この知見に基づけば、室内温湿度の時系列データに含まれる周波数成分には、その建物の性能に関する情報が埋め込まれていると考えられる。もしこの情報を適切に抽出し、機械学習などを組み合わせて逆推定に利用できれば、現状では経験的に行われているパラメータ調整を理論に基づいて行うことが可能になると期待される。その妥当性や限界を基礎的に検討することが、本研究の出発点である。

## 本研究の目的

　本研究の最終的な目標は、自然室温下で測定される室内温湿度データをFFT解析により周波数領域に変換し、その特徴量から建物性能（壁構造・換気量など）を機械学習により逆推定する手法を確立することである。

　この目標に向けて、本研究では以下のステップを設定する。

1. **シミュレーション環境の構築**

　Juliaで実装された熱水分同時移動解析プログラムを用い、壁材料・換気量などをパラメータとして変化させた複数の建物モデルを作成する。各モデルについて外気条件を与えた時の室内温湿度応答を、自然室温（非空調）条件で長期間シミュレーションし、データセットを構築する。

2. **FFT解析による特徴量抽出**

　得られた室内温湿度の時系列データに対してFFT解析を行い、日周期・半日周期・月周期・年周期などの主要周波数ごとの振幅と位相を求める。外気と室内の振幅比・位相差なども特徴量として抽出する。

3. **周波数特徴量と建物性能の対応関係の分析**

　壁構造・換気量の違いが、どの周波数帯の振幅・位相にどのように現れるのかを分析し、周波数特徴量から建物性能を識別できる可能性を検討する。

4. **機械学習による逆推定モデルの構築**（今後の課題）

　上記の周波数特徴量を入力として、壁構造や換気量を出力する機械学習モデル（分類器）を構築し、逆推定の精度と限界を評価する。

　本論文では、上記のステップ1〜3までを実施する。すなわち、シミュレーションによるデータ生成、FFT解析による周波数特徴量の抽出、および周波数特徴量と建物性能の対応関係の分析までを行う。ステップ4の機械学習による逆推定モデルの構築は今後の課題とする。

　卒業論文としての目標は、「周波数特徴量に建物性能の違いがどのように現れるかを明らかにし、どの程度まで性能の違いを識別できる可能性があるのかを検討すること」である。この結果を通じて、将来的に機械学習を用いた逆推定手法を構築するための基礎を築くことを本研究の狙いとする。
