# 熱水分同時移動シミュレーションとデータ生成

## Julia 熱水分同時移動シミュレーションの概要

### プログラムの機能

本研究では、建物内の温湿度環境を数値的に再現するために、Juliaで実装された熱水分同時移動解析プログラムを用いる。このプログラムは建物を構成する、室・壁体・　開口部をネットワークとして接続し、外気条件の時間変化に応じた室内温室どの応答を非定常で計算するものである。

　本プログラムの主要な機能は以下の通りである。

- 建物ネットワークモデルの構築

室空間、壁体、開口部、外気の4要素をネットワークとして定義する。各要素館の接続関係はインシデンス行列として管理され、熱・水分の流れを追跡できる構造となっている。壁体は外気と室内空気を隔てる媒介として機能し、開口部は換気による空気の移動経路を表す。これにより、壁体を通じた伝導・対流・吸放湿と、換気による顕熱・潜熱の移動を同時に考慮できる。

- 壁体内の熱・水分同時移動解析

壁体は厚さ方向に有限個のセルに分割され、各セルにおいて熱・水蒸気・液水の移動が計算される。熱移動はフーリエの法則（熱伝導）と対流熱伝達、水分移動は水分化学ポテンシャルを駆動力とする拡散則に基づいて評価される。壁体表面では第三種境界条件（Robin条件）を適用し室内空気あるいは外気との熱・水分交換を計算する。

- 室空気の熱・水分収支計算

室空気は完全混合を仮定し、壁体からの熱流入・流出と換気による熱移動の収支から温度を、同時に壁体からの水蒸気流入・流出と換気による水分移動の収支から湿度を算出する。室に複数の壁体や開口部が接続する場合、それぞれの寄与を積算して全体の収支を評価する。

- 換気による熱・水分輸送

開口部を介した換気は風上差分法により計算される。すなわち、流入側の空気が持つ熱量・水分量が流出側に輸送されるものとして扱い、上流室方向流量と下流室方向流量を指定することで双方向の換気を表現できる。これにより、隙間風や自然換気のような低風量から、強制換気のような高風量まで対応可能である。

- 外気条件の時系列更新

外気温度・外気湿度は標準気象データから時刻に応じて線形保管される。計算ループの各ステップで気象データが更新され、外乱として建物モデルに入力される。これにより、日変動・季節変動を含む長期間のシミュレーションが可能となる。

- 結露判定と収束処理

壁体内部あるいは表面で水分科学ポテンシャルが飽和値に達した場合、結露が発生したと判定し、過剰な水分を表面水として処理する。これにより、結露発生時にも計算の安定性が保たれる。

　以上の機能により、本プログラムは自然室温下での建物内温湿度応答を物理的に妥当な形で長期間にわたり計算できる。本研究では、この出力結果を逆推定の学習データとして活用する。

### 支配方程式と離散化の概要

　本プログラムで解く支配方程式は、第3章で述べた熱水分同時移動方程式を基礎としている。以下に、壁体内および室空気に対する支配方程式と、その数値解法を示す。

**壁体内の熱移動**

　壁体内の熱移動は、フーリエの法則に基づく熱伝導と、水分の相変化に伴う潜熱輸送を考慮して、以下の式で表される。

$$
\rho c \frac{\partial T}{\partial t} = \frac{\partial}{\partial x}\left(\lambda \frac{\partial T}{\partial x}\right) - r \frac{\partial J_v}{\partial x} \tag{4-1}
$$

ここで、$\rho$ は材料の密度 [kg/m³]、$c$ は比熱 [J/(kg·K)]、$T$ は温度 [K]、$\lambda$ は熱伝導率 [W/(m·K)]、$r$ は水の蒸発潜熱 [J/kg]、$J_v$ は水蒸気流束 [kg/(m²·s)] である。

　熱伝導による熱流束 $q$ [W/m²] は、フーリエの法則により

$$
q = -\lambda \frac{\partial T}{\partial x} \tag{4-2}
$$

と表される。

**壁体内の水蒸気移動**

　水蒸気移動は、水分化学ポテンシャル $\mu$ [J/kg] を駆動力として以下の式で表される。

$$
\rho_w \frac{\partial \psi}{\partial \mu}\frac{\partial \mu}{\partial t} = \frac{\partial}{\partial x}\left(\lambda'_\mu \frac{\partial \mu}{\partial x} + \lambda'_T \frac{\partial T}{\partial x}\right) \tag{4-3}
$$

ここで、$\rho_w$ は水の密度 [kg/m³]、$\psi$ は体積含水率 [-]、$\lambda'_\mu$ は水分化学ポテンシャル勾配に対する湿気伝導率 [kg/(m·s·(J/kg))]、$\lambda'_T$ は温度勾配に対する湿気伝導率 [kg/(m·s·K)] である。

　水蒸気流束 $J_v$ [kg/(m²·s)] は

$$
J_v = -\lambda'_\mu \frac{\partial \mu}{\partial x} - \lambda'_T \frac{\partial T}{\partial x} \tag{4-4}
$$

と表される。

**壁体内の液水移動**

　液水移動は、水分化学ポテンシャル勾配と重力を駆動力として

$$
J_l = -\lambda'_l \left(\frac{\partial \mu}{\partial x} - n_x \cdot g\right) \tag{4-5}
$$

と表される。ここで、$\lambda'_l$ は液水伝導率 [kg/(m·s·(J/kg))]、$n_x$ は重力方向の方向余弦、$g$ は重力加速度 [m/s²] である。

**室空気の熱収支**

　室空気の温度変化は、壁体からの熱流入、換気による熱移動、内部発熱の収支から決まる。

$$
\rho_a c_a V \frac{dT_r}{dt} = Q_{wall} + Q_{vent} + Q_{in} \tag{4-6}
$$

ここで、$\rho_a$ は空気密度 [kg/m³]、$c_a$ は空気の比熱 [J/(kg·K)]、$V$ は室容積 [m³]、$T_r$ は室温 [K]、$Q_{wall}$ は壁体からの熱流入 [W]、$Q_{vent}$ は換気による熱流入 [W]、$Q_{in}$ は内部発熱 [W] である。

　空気密度は理想気体の状態方程式から

$$
\rho_a = \frac{353.25}{T_r} \tag{4-7}
$$

と計算される。また、湿り空気の比熱は絶対湿度 $X$ [kg/kg] を用いて

$$
c_a = 1005 + 1846 \cdot X \tag{4-8}
$$

と表される。

**室空気の水分収支**

　室空気の絶対湿度変化は、壁体からの水分流入、換気による水分移動、内部発湿の収支から決まる。

$$
\rho_a V \frac{dX_r}{dt} = J_{wall} + J_{vent} + J_{in} \tag{4-9}
$$

ここで、$X_r$ は室内絶対湿度 [kg/kg]、$J_{wall}$ は壁体からの水分流入 [kg/s]、$J_{vent}$ は換気による水分流入 [kg/s]、$J_{in}$ は内部発湿 [kg/s] である。

**換気による熱・水分輸送**

　開口部を通じた換気による熱流量 $Q_{vent}$ と水分流量 $J_{vent}$ は、風上差分法により

$$
Q_{vent} = Q_v \cdot \rho_a \cdot c_a \cdot (T_{up} - T_{down}) \tag{4-10}
$$

$$
J_{vent} = Q_v \cdot \rho_a \cdot (X_{up} - X_{down}) \tag{4-11}
$$

と計算される。ここで、$Q_v$ は換気量 [m³/s]、添字 $up$ と $down$ はそれぞれ上流側と下流側を表す。

**飽和水蒸気圧と水分化学ポテンシャル**

　飽和水蒸気圧 $P_{vs}$ [Pa] は温度の関数として以下の式で計算される。

$$
P_{vs} = \exp\left(-\frac{5800.22}{T} + 1.3915 - 4.864 \times 10^{-2} T + 4.176 \times 10^{-5} T^2 - 1.445 \times 10^{-8} T^3 + 6.546 \ln T\right) \tag{4-12}
$$

　水分化学ポテンシャル $\mu$ は相対湿度 $h$ [-] から

$$
\mu = R_v T \ln(h) \tag{4-13}
$$

と計算される。ここで、$R_v = 461.5$ J/(kg·K) は水蒸気のガス定数である。

**数値解法**

　本プログラムでは、上記の支配方程式を有限差分法（Finite Difference Method）により離散化し、陽解法（Forward Euler法）で時間積分を行う。

| 項目 | 方法 |
|------|------|
| 空間離散化 | 有限差分法（セル中心配置） |
| 時間積分 | 陽解法（Forward Euler） |
| 時間刻み | $\Delta t = 0.1$ h（360 s） |
| 計算期間 | 1年間（8760時間） |

　温度の更新式は

$$
T^{n+1} = T^n + \frac{\Delta t}{\rho c}\left(\frac{\Delta q}{\Delta x} - r \cdot W\right) \tag{4-14}
$$

と表される。ここで、$n$ は時間ステップ、$\Delta q$ はセル境界における熱流束の差、$W$ は相変化に伴う水分量変化である。

　水分化学ポテンシャルの更新式は

$$
\mu^{n+1} = \mu^n + \frac{\Delta t}{\rho_w \cdot \partial\psi/\partial\mu}\frac{\Delta J_w}{\Delta x} \tag{4-15}
$$

と表される。ここで、$\Delta J_w$ は水分流束（水蒸気＋液水）の差である。

　セル間の物性値は、隣接セルの値を抵抗直列として平均化する。熱伝導率を例にとると、

$$
\bar{\lambda} = \frac{\Delta x_- + \Delta x_+}{\Delta x_-/\lambda_- + \Delta x_+/\lambda_+} \tag{4-16}
$$

と計算される。ここで、添字 $-$ と $+$ はセル境界の両側を表す。

### データ構造

　本プログラムでは、建物の構成要素をオブジェクト指向的に構造体として定義し、それらをネットワークとして接続することで建物全体のモデルを構築する。主要な構造体を以下に示す。

**Cell（壁体セル）**

　壁体内の各セル（微小体積要素）の状態を表現する構造体である。

| 変数名 | 型 | 単位 | 説明 |
|--------|-----|------|------|
| material_name | String | - | 材料名 |
| temp | Float64 | K | 温度 |
| miu | Float64 | J/kg | 水分化学ポテンシャル |
| dx | Float64 | m | セル幅 |
| dx2 | Float64 | m | セル中心から境界までの距離 |
| Q | Array | W | 熱流量（6方向） |
| Jv | Array | kg/s | 水蒸気流量（6方向） |
| Jl | Array | kg/s | 液水流量（6方向） |

**Wall（壁体）**

　壁体全体の構成と特性を管理する構造体である。

| 変数名 | 型 | 単位 | 説明 |
|--------|-----|------|------|
| num | Int | - | 壁番号 |
| IP, IM | Int | - | 接続する室番号 |
| ION | Float64 | ° | 傾斜角 |
| thickness | Float64 | m | 壁厚さ |
| area | Float64 | m² | 壁面積 |
| cell | Array{Cell} | - | セル配列 |
| BC_IP, BC_IM | BC_Robin | - | 境界条件 |

**Room（室）**

　室空間の状態を管理する構造体である。

| 変数名 | 型 | 単位 | 説明 |
|--------|-----|------|------|
| num | Int | - | 室番号 |
| name | String | - | 室名 |
| vol | Float64 | m³ | 室容積 |
| air | Air | - | 室内空気の状態 |
| Qs | Float64 | W | 顕熱発生量 |
| Js | Float64 | kg/s | 湿気発生量 |

**Opening（開口部）**

　室間・室と外気の換気経路を定義する構造体である。

| 変数名 | 型 | 単位 | 説明 |
|--------|-----|------|------|
| IP, IM | Int | - | 上流・下流室番号 |
| Type | String | - | 換気タイプ |
| Qup, Qdw | Float64 | m³/s | 上流・下流方向の風量 |

**BNM（Building Network Model）**

　建物全体のネットワークモデルを管理する最上位の構造体である。

| 変数名 | 型 | 説明 |
|--------|-----|------|
| rooms | Array{Room} | 室配列 |
| walls | Array{Wall} | 壁体配列 |
| openings | Array{Opening} | 開口部配列 |
| climate | Climate | 気象データ |
| IC_walls | Matrix | 室-壁のインシデンス行列 |
| IC_openings | Matrix | 室-開口のインシデンス行列 |

## 入力データとJuliaコードの対応関係

　本節では、シミュレーションの入力データとして用いるCSVファイルの構造と、Juliaプログラムにおける対応関係を説明する。

### 部屋構造

　室条件は `room-condition/*.csv` ファイルで定義する。本研究では、外気（outdoor）と解析対象室（indoor）の2室構成とした。

| カラム | 変数名 | 単位 | 説明 |
|--------|--------|------|------|
| num | 室番号 | - | 1から連番（1は外気として固定） |
| name | 室名 | - | outdoor / indoor |
| vol | 容積 | m³ | 室容積（outdoor: 1000, indoor: 62.5） |
| temp | 温度 | ℃ | 初期温度 |
| rh | 湿度 | % | 初期相対湿度 |
| Hight | 室高さ | m | 室高さ（2.5 m） |
| Qs | 顕熱量 | W | 内部発熱（本研究では0） |
| Js | 湿気量 | kg/s | 内部発湿（本研究では0） |
| AC | 空調 | - | 空調有無（本研究ではOFF） |

　本研究では、室容積を $V = 62.5$ m³（$5 \times 5 \times 2.5$ m）の標準的な居室を想定し、内部発熱・発湿はゼロ、空調は無しとして自然室温条件を実現した。

### 開口部構造

　開口・換気条件は `opening-condition/*.csv` ファイルで定義する。換気量を変化させた5パターンを用意した。

| カラム | 変数名 | 単位 | 説明 |
|--------|--------|------|------|
| BC | 枝番号 | - | 開口番号 |
| IP | 上流側 | - | 上流側室番号（1: outdoor） |
| IM | 下流側 | - | 下流側室番号（2: indoor） |
| Type | タイプ | - | 換気タイプ（constant: 定風量） |
| Qup | 上流風量 | m³/s | 上流→下流の風量 |
| Qdw | 下流風量 | m³/s | 下流→上流の風量 |

　本研究では、Type を `constant`（定風量）とし、双方向に同一の換気量を設定した。

### 壁構造

　壁条件は `wall-condition/*.csv` ファイルで定義する。壁体の層構成は、別途 `cell-data/*.csv` ファイルで詳細に指定する。

| カラム | 変数名 | 単位 | 説明 |
|--------|--------|------|------|
| num | 壁番号 | - | 壁番号 |
| IP | 上流側 | - | 外気側室番号（1） |
| IM | 下流側 | - | 室内側室番号（2） |
| Type | タイプ | - | セルデータファイル名 |
| thickness | 厚さ | m | 壁厚さ |
| area | 面積 | m² | 壁面積（100 m²） |
| ION | 傾斜角 | ° | 傾斜角（90: 垂直壁） |
| alphac_IP | 対流熱伝達率 | W/(m²·K) | 外表面（19） |
| alphac_IM | 対流熱伝達率 | W/(m²·K) | 内表面（4.9） |
| alphar_IP | 放射熱伝達率 | W/(m²·K) | 外表面（4.4） |
| alphar_IM | 放射熱伝達率 | W/(m²·K) | 内表面（4.4） |

　本研究では、6面の壁体を面積100 m²の1枚の壁体に統合して計算効率を高めた。日射吸収率を0としているため、方位・傾斜角による日射影響はない。

　壁体の層構成は、`cell-data/*.csv` ファイルで各セルの材料名、セル幅、初期条件を指定する。例として、RC単層壁（P0）のセルデータを示す。

| セル番号 | セル幅 [m] | 材料名 |
|----------|-----------|--------|
| 1 | 0.005 | concrete_goran |
| 2-15 | 0.010 | concrete_goran |
| 16 | 0.005 | concrete_goran |

　このように、150 mm厚のコンクリート壁を16セルに分割している。表面近傍は細かく、中央部は粗く分割することで、計算精度と効率のバランスを取っている。

## 本研究で用いる構造パターン

　本研究では、建物性能の違いが室内温湿度の周波数応答にどのように現れるかを検証するため、壁構造・換気量・気候条件を組み合わせた75パターンのシミュレーションを実施した。

### 部屋構造のパターン

　室構造は全パターンで共通とし、以下の条件を用いた。

| 項目 | 値 | 備考 |
|------|-----|------|
| 室容積 | 62.5 m³ | 5 m × 5 m × 2.5 m |
| 初期温度 | 25 ℃ | - |
| 初期湿度 | 50 % | - |
| 内部発熱 | 0 W | 自然室温条件 |
| 内部発湿 | 0 kg/s | 自然室温条件 |
| 空調 | OFF | 自然室温条件 |

　室条件を固定することで、壁構造と換気量の違いが周波数応答に与える影響を純粋に評価できるようにした。

### 開口部構造のパターン

　換気量を変化させた5パターンを設定した。換気回数 $n$ [1/h] は、換気量 $Q_v$ [m³/s] と室容積 $V$ [m³] から $n = 3600 Q_v / V$ で計算される。

| パターン | 名称 | 換気量 [m³/s] | 換気回数 [1/h] | 特徴 |
|----------|------|--------------|---------------|------|
| O1 | 標準換気 | 0.005 | 0.5 | 一般的な住宅の換気量 |
| O2 | 弱換気 | 0.0015 | 0.1 | ほぼ密閉状態 |
| O3 | 強換気 | 0.020 | 1.0 | 換気量が多い状態 |
| O4 | 無換気 | 0.0 | 0.0 | 理論的限界（完全密閉） |
| O5 | 蔵換気 | 0.010 | 2.0 | 蔵・倉庫相当 |

　換気量の範囲は、実際の建物で想定される0〜2.0回/hをカバーしている。

### 壁構造のパターン

　壁構造として、蓄熱性・断熱性・吸放湿性の異なる5パターンを設定した。

| パターン | 名称 | 材料構成（外→内） | 総厚 | 特徴 |
|----------|------|------------------|------|------|
| W1 | RC単層 | concrete_goran | 150 mm | 高蓄熱・非吸放湿 |
| W2 | RC内断熱 | concrete_goran → glass_wool_16K | 250 mm | 蓄熱が外気側 |
| W3 | RC外断熱 | glass_wool_16K → concrete_goran | 250 mm | 蓄熱が室内側 |
| W4 | RC内断熱+吸放湿 | concrete_goran → glass_wool_16K → plasterboard → paper_washi | 262.5 mm | 吸放湿内装あり |
| W5 | 土壁 | mud_wall | 70 mm | 高調湿性・伝統構法 |

　各パターンの材料物性値を以下に示す。

| 材料 | 熱伝導率 $\lambda$ | 密度 $\rho$ | 比熱 $c$ | 特徴 |
|------|-------------------|-------------|----------|------|
| concrete_goran | 1.3 W/(m·K) | 2200 kg/m³ | 940 J/(kg·K) | 高蓄熱 |
| glass_wool_16K | 0.045 W/(m·K) | 16 kg/m³ | 698 J/(kg·K) | 高断熱 |
| plasterboard | 0.22 W/(m·K) | 787 kg/m³ | 870 J/(kg·K) | 一般内装 |
| paper_washi | 0.08 W/(m·K) | 600 kg/m³ | 1350 J/(kg·K) | 吸放湿 |
| mud_wall | 0.23 W/(m·K) | 1650 kg/m³ | 900 J/(kg·K) | 高調湿 |

　W1（RC単層）は高い熱容量を持ち、室温変動を緩和する蓄熱効果が期待される。W2（RC内断熱）とW3（RC外断熱）は同じ材料構成だが断熱材の位置が異なり、蓄熱体（コンクリート）が外気側にあるか室内側にあるかで室温応答が異なる。W4（RC内断熱+吸放湿）は吸放湿性を有する内装材を追加したパターンである。W5（土壁）は伝統的な構法であり、高い調湿性能を有する。

## シミュレーション実行と出力データ

### メイン計算ループ

　シミュレーションのメイン計算ループは以下の手順で構成される。

1. **初期化**: 入力ファイルを読み込み、BNMモデルを構築する。
2. **時間ループ**: 指定期間（1年間）について、以下のステップを繰り返す。
   - 気象データの補間更新
   - 壁体の熱・水分流量計算
   - 換気の熱・水分流量計算
   - 新値計算（温度・水分化学ポテンシャル・室温・室内湿度の更新）
   - 時間進行
   - 出力（指定間隔ごと）
3. **終了処理**: 結果ファイルを閉じる。

　時間ループの1ステップにおける計算順序を模式的に示すと以下のようになる。

```
while date ≠ END_DATE:
    (1) 気象データ補間      → 外気温・外気湿度を現在時刻に更新
    (2) 壁体流量計算        → 各セル間の熱・水分流量を算出
    (3) 換気流量計算        → 開口部を通じた熱・水分流量を算出
    (4) 新値計算            → 収支式により温度・湿度を更新
    (5) 時間進行            → date += Δt
    (6) 出力                → 指定間隔でファイルに書き込み
```

　壁体流量計算では、各セル間の熱伝導・水蒸気拡散・液水移動を式(4-2)〜(4-5)に基づいて計算する。境界条件（壁体表面と空気の界面）では、対流熱伝達率と湿気伝達率を用いて熱・水分交換を評価する。

　結露判定は、水分化学ポテンシャルが飽和値（$\mu \geq -0.1$ J/kg）に達した場合に行い、過剰な水分は表面結露水として処理する。

### 出力データ構造

　シミュレーション結果は、以下のCSVファイルとして出力される。

**result_all_rooms.csv（全室の温湿度）**

　全室の時系列データを記録する。

| カラム | 単位 | 説明 |
|--------|------|------|
| date | - | 日時 |
| temp | ℃ | 温度 |
| rh | - | 相対湿度（0〜1） |
| ah | kg/kg | 絶対湿度 |

　本研究のFFT解析では、このファイルから室内温度と室内相対湿度の時系列を抽出して使用する。

**result_wall*.csv（壁体内の温湿度分布）**

　壁体の各セルの状態を記録する。

| カラム | 単位 | 説明 |
|--------|------|------|
| temp | ℃ | 温度 |
| rh | - | 相対湿度 |
| ah | kg/kg | 絶対湿度 |
| phi | kg/m³ | 含水率 |

**result_room_analysis*.csv（室の熱・水分収支分析）**

　室ごとの詳細な収支データを記録する。壁体表面からの熱流・水分流、換気による熱流・水分流、内部発熱・発湿を個別に記録することで、各要因の寄与を分析できる。

**settings.txt（計算条件）**

　各パターンの計算条件（入力ファイル、計算開始時刻、時間刻み、出力間隔など）を記録する。再現性の確保と計算条件の確認に用いる。
