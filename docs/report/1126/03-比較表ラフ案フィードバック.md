# 比較表ラフ案 フィードバック

## 概要

`02-比較表ラフ案.md` の内容と、実際のJuliaコード・入力ファイルを照合した結果、以下の問題点が確認されました。

---

## 1. 壁構成（cell_data）の説明が逆【重大】

### 問題

比較表の説明と実際のファイル内容が**逆転**しています。

| 比較表の記載 | 実際のファイル構成 |
|-------------|------------------|
| wall2_2.csv（RC**内**断熱2層） | EPS → concrete_goran（断熱材が**外側** = **外断熱**） |
| wall2_1.csv（RC**外**断熱2層） | concrete_goran → EPS（断熱材が**内側** = **内断熱**） |

### 実際のファイル内容

**wall2_1.csv**（外側から順に）:
```
concrete_goran × 16セル → extruded_polystyrene × 5セル
```
→ RC外側、断熱材内側 = **内断熱**

**wall2_2.csv**（外側から順に）:
```
extruded_polystyrene × 5セル → concrete_goran × 16セル
```
→ 断熱材外側、RC内側 = **外断熱**

### 修正案

| パターン | cell_data | 正しい説明 |
|---------|-----------|-----------|
| P1 | wall2_1.csv | RC＋**内**断熱 |
| P2 | wall2_2.csv | RC＋**外**断熱 |

## 4. thickness 値の整合性【中程度】

### 問題

mud_wall.CSV の厚さが比較表と不整合。

| パターン | 比較表の値 | cell_data dx合計 | 状態 |
|---------|-----------|-----------------|------|
| wall1.csv | 0.225m | 約0.22m | ほぼOK |
| wall2_1.csv | 0.175m | 約0.175m | OK |
| wall2_2.csv | 0.175m | 約0.175m | OK |
| mud_wall.CSV | **0.15m** | **0.175m** | **不整合** |

### mud_wall.CSV のdx詳細

```
0.005 + 0.01×3 + 0.015 + 0.02 + 0.03×2 + 0.02 + 0.015 + 0.01×3 + 0.005 = 0.175m
```

### 修正案

比較表の mud_wall thickness を `0.175m` に修正、または cell_data を修正。
