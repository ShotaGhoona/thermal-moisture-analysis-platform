# 壁構成（material）追加パターン案

## 現在の5パターン

| パターン | 構成 | 特徴 |
|---------|-----|------|
| P0 | 単層RC | 高蓄熱・非調湿 |
| P1 | RC＋内断熱 | 高蓄熱・断熱強化 |
| P2 | RC＋外断熱 | 高蓄熱・断熱強化・躯体保護 |
| P3 | RC＋内断熱＋吸放湿内装 | 高蓄熱・調湿 |
| P4 | 伝統土壁 | 中蓄熱・高調湿 |

## 追加パターン案

### 木造系

- **木造在来工法（グラスウール断熱）**
  - 構成: plywood → glass_wool_16K → vented_air_space → plasterboard
  - 特徴: 低蓄熱・高断熱・一般住宅標準
  - 材料: `plywood`, `glass_wool_16K`, `vented_air_space`, `plasterboard`

- **木造高断熱仕様**
  - 構成: plywood → glass_wool_16K（厚め） → moisture_proof_sheet → plasterboard
  - 特徴: 低蓄熱・超高断熱・省エネ住宅
  - 材料: `plywood`, `glass_wool_16K`, `moisture_proof_sheet`, `plasterboard`

- **木造＋土壁（伝統×現代ハイブリッド）**
  - 構成: plywood → mud_wall → paper
  - 特徴: 低〜中蓄熱・高調湿・古民家改修
  - 材料: `plywood`, `mud_wall`, `paper`

### 鉄骨・軽量構造系

- **ALC外壁（軽量気泡コンクリート）**
  - 構成: ALC単層 または ALC → vented_air_space → plasterboard
  - 特徴: 中蓄熱・中断熱・中層建築標準
  - 材料: `ALC`, `vented_air_space`, `plasterboard`

- **窯業系サイディング外壁**
  - 構成: ceramic_siding → vented_air_space → glass_wool_16K → plasterboard
  - 特徴: 低蓄熱・高断熱・戸建住宅標準
  - 材料: `ceramic_siding`, `vented_air_space`, `glass_wool_16K`, `plasterboard`

- **金属サイディング外壁**
  - 構成: metal_plate → vented_air_space → extruded_polystyrene → plasterboard
  - 特徴: 極低蓄熱・高断熱・倉庫/工場
  - 材料: `metal_plate`, `vented_air_space`, `extruded_polystyrene`, `plasterboard`

### RC系バリエーション

- **RC＋モルタル仕上げ（打放し風）**
  - 構成: mortar → concrete_goran
  - 特徴: 高蓄熱・低断熱・意匠建築
  - 材料: `mortar`, `concrete_goran`

- **RC＋内断熱（グラスウール）**
  - 構成: concrete_goran → glass_wool_16K → plasterboard
  - 特徴: 高蓄熱・高断熱・EPS代替
  - 材料: `concrete_goran`, `glass_wool_16K`, `plasterboard`

- **RC二重壁（中空層あり）**
  - 構成: concrete_goran → vented_air_space → concrete_goran
  - 特徴: 超高蓄熱・中断熱・大型施設
  - 材料: `concrete_goran`, `vented_air_space`

### 特殊・伝統系

- **石造（凝灰�ite）**
  - 構成: tuff_motomachi 単層
  - 特徴: 高蓄熱・高調湿・歴史的建造物
  - 材料: `tuff_motomachi`

- **土蔵壁（厚土壁）**
  - 構成: mud_wall（厚め 0.3m程度）
  - 特徴: 超高蓄熱・超高調湿・蔵/倉庫
  - 材料: `mud_wall`

- **版築壁**
  - 構成: mud_wall + mortar の複合
  - 特徴: 高蓄熱・高調湿・伝統工法
  - 材料: `mud_wall`, `mortar`

## 研究目的別の推奨追加パターン

### FFT解析で差が出やすい組み合わせ

| 追加パターン | 理由 |
|-------------|-----|
| **木造在来（グラスウール）** | RCと蓄熱特性が大きく異なる |
| **ALC外壁** | RC/木造の中間的特性 |
| **金属サイディング** | 極端に低い蓄熱→高周波応答顕著 |
| **石造（凝灰岩）** | RCと異なる高蓄熱特性 |

### 調湿性能比較向け

| 追加パターン | 理由 |
|-------------|-----|
| **木造＋土壁ハイブリッド** | 土壁の調湿を木造で包む |
| **厚土壁（土蔵）** | 極端な調湿性能 |
| **RC＋防湿シート** | 調湿ゼロの基準ケース |
