## 4. パターン別変更要素サマリー

### simple → concrete_low
```
変更要素: なし
理由: 完全同一（基準パターン）
```

### simple → concrete_high  
```
変更要素: 換気量 0.005 → 0.5 m³/s (100倍)
理由: 強換気による外気影響度の変化検証
```

### simple → wood_low
```
変更要素: 材料 concrete_goran → wood
理由: 蓄熱特性の変化（高蓄熱 → 低蓄熱・高断熱）
```

### simple → wood_high
```
変更要素: 
- 材料 concrete_goran → wood
- 換気量 0.005 → 0.5 m³/s
理由: 材料×換気量の複合効果検証
```

### 統制変数（Fixed Variables）
✅ **室構成**: 全パターン同一（2室、容積、初期条件等）  
✅ **壁体構造**: 全パターン同一（厚さ、面積、方位等）

## 7. 建物特性逆算評価への活用

### パターン認識アルゴリズム
```
if (温度変動小 && 湿度安定) → 断熱材料 + 微換気
if (温度変動大 && 外気追従) → 任意材料 + 強換気  
if (位相遅れ大 && 振幅減衰大) → 蓄熱材料 + 微換気
if (位相遅れ小 && 振幅減衰小) → 断熱材料 + 強換気
```

### 実用的判定基準
各パターンの特徴的な「指紋」パターンを定量化し、実測データから建物の材料特性・換気特性を逆算推定する手法の確立が可能。
