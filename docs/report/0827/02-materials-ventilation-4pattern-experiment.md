# 材料×換気量4パターン実験設計 - 建物特性逆算評価手法の開発 - 2025/08/27

## 実験概要

**目的**: 材料と換気量の組み合わせによる建物熱環境特性の定量評価手法開発  
**手法**: simpleモデルをベースとした2×2factorial design  
**評価指標**: 温度・相対湿度・絶対湿度の時系列変化パターン分析

---

## 4パターン実験設計

### 実験変数

| 変数 | 水準1 | 水準2 | 設計意図 |
|------|-------|--------|----------|
| **材料** | concrete_goran | wood | 蓄熱特性の対比 |
| **換気量** | 0.005 m³/s | 0.5 m³/s | 外気影響度の対比 |

### パターン構成

#### Pattern 1: concrete_low
- **壁材料**: コンクリート（高蓄熱・低断熱）
- **換気量**: 0.005 m³/s（微換気）
- **特徴**: 壁体蓄熱効果が支配的、温度変動緩慢

#### Pattern 2: concrete_high  
- **壁材料**: コンクリート（高蓄熱・低断熱）
- **換気量**: 0.5 m³/s（強換気）
- **特徴**: 外気影響大、但し壁体が温度変動を緩衝

#### Pattern 3: wood_low
- **壁材料**: 木材（低蓄熱・高断熱）
- **換気量**: 0.005 m³/s（微換気）
- **特徴**: 断熱効果重視、外気変動から遮断

#### Pattern 4: wood_high
- **壁材料**: 木材（低蓄熱・高断熱）  
- **換気量**: 0.5 m³/s（強換気）
- **特徴**: 外気追従性高、断熱材の効果限定的

## 分析フレームワーク

### 1. 時間スケール別分析
- **1日**: 日中の最大・最小値の差
- **1週間**: 周期性パターンの有無
- **1年間**: 季節変動の追従性

### 2. 建物特性の逆算評価指標

#### 蓄熱性評価
```
指標: 外気温度変動に対する室内温度の位相遅れ
concrete系 > wood系 (予想)
```

#### 断熱性評価  
```
指標: 外気温度振幅に対する室内温度振幅の比
wood系 < concrete系 (予想)
```

#### 換気効果評価
```
指標: 換気量変化による室内環境応答の差
high換気 >> low換気 (全パターン共通)
```

### 3. 建物判定アルゴリズム

**Step 1**: 温度変動パターン分析
- 周期性の有無 → 外気影響度
- 振幅の大小 → 断熱性能
- 位相差 → 蓄熱性能

**Step 2**: 湿度制御パターン分析  
- 相対湿度の安定性 → 調湿性能
- 絶対湿度の追従性 → 換気効率

**Step 3**: 総合判定
```
"この建物は換気量○○で、材料は○○の特徴を示している"
→ 逆算的建物特性評価の実現
```
