## cell_dataとは

### 概要
`cell_data`フォルダには、**多層壁体構成**の詳細データが格納されています。単一材料ではなく、複数の材料を組み合わせた実際の建築構法をモデル化したものです。

### 対象構成要素
- **壁体**: 外壁・内壁・構造壁
- **天井**: 各種天井構成
- **床**: 構造床・二重床・断熱床
- **屋根**: 金属屋根・断熱屋根
- **特殊**: 地盤・収納物

### 収録データ数
**20ファイル**の多層構成データを収録

## 壁体構成詳細分析

### 🏆 最高性能壁：wall.CSV（現代外断熱工法）

```
【外側】ceramic_siding (0.10m)
        ↓ 耐候性・調湿性
        extruded_polystyrene (0.10m)  
        ↓ 高断熱性（λ=0.03W/mK）
        vented_air_space (0.10m)
        ↓ 結露防止・湿気排出
【内側】structural_plywood (0.009m)
```

**設計思想**:
- **外断熱方式**: 構造体を断熱層で包む
- **通気層**: 結露・湿害防止の完全対策
- **調湿外装**: セラミックサイディングによる湿度制御

**熱性能**: 高断熱（U値≈0.25 W/m²K相当）
**湿気性能**: 透湿・通気による湿害回避

### 🏢 RC造標準：wall1.csv（内断熱工法）

```
【外側】concrete_goran (0.155m)
        ↓ 構造強度・耐久性
        extruded_polystyrene (0.02m)
        ↓ 内断熱層
        vented_air_space (0.04m) 
        ↓ 内部結露対策
        plasterboard (0.009m)
        ↓ 内装下地
【内側】paper (0.001m)
```

**設計思想**:
- **内断熱方式**: RC構造＋内側断熱
- **ヒートブリッジ**: 構造体の熱橋がある
- **標準仕様**: 中高層建築の一般的構成

**熱性能**: 中程度断熱（構造体熱橋あり）
**施工性**: 標準的・経済的

### 🌿 伝統構法：mud_wall.CSV（土壁）

```
【単層】mud_wall (0.15m)
       ↓ 調湿・蓄熱・透湿
```

**設計思想**:
- **一体構造**: 構造・断熱・調湿を同時実現
- **自然調湿**: 高い吸放湿性能
- **蓄熱効果**: 温度変動の緩和

**環境性能**: 
- 調湿性能: 優秀（φ=0.002+0.03×RH）
- 蓄熱性能: 良好（ρ=1650kg/m³）
- 断熱性能: 中程度（λ=0.23W/mK）

### ⚡ 高性能複合：wall5.csv（多機能壁）

```
【外側】paper (0.001m)
        ↓ 外装仕上げ
        plasterboard (0.009m)
        ↓ 下地・防火
        vented_air_space (0.05m)
        ↓ 通気・除湿
        extruded_polystyrene (0.02m)
        ↓ 断熱層
        concrete_goran (0.155m)
        ↓ 構造体
【内側】mortar (0.025m)
```

**設計思想**:
- **完全機能分離**: 各層が独立した機能
- **最高性能**: 断熱・調湿・構造の最適化
- **研究仕様**: 実験・検証用の理想構成

## 天井・床・屋根の特徴分析

### 🏗️ 天井構成の工学的特徴

#### ceiling1.csv - 高性能天井
```
【上側】paper + plasterboard
        ↓ 内装仕上げ
        vented_air_space (0.7m)  ★大容量通気層
        ↓ 強力な断熱効果
        concrete_goran (0.155m)
        ↓ 構造・耐火
【下側】mortar
```

**工学的意義**:
- **0.7mの通気層**: 極めて高い断熱性能
- **熱容量効果**: RC構造による温度安定化
- **防火性能**: 不燃材料による安全性確保

### 🔽 床構成の多様性

#### floor1.csv - 二重床システム
```
【上側】plywood (0.009m)
        ↓ 仕上げ床
        vented_air_space (0.2m)
        ↓ 配管・配線・断熱空間
        concrete_goran (0.155m)
        ↓ 構造床
【下側】plywood (0.006m)
```

**機能性**:
- **メンテナンス性**: 配管・配線の更新容易
- **遮音性能**: 二重構造による音響制御
- **断熱性能**: 空気層による熱的分離

#### floor3.csv - 重荷重対応床
```
concrete_goran (0.155m)
+ mortar (0.155m)  
+ concrete_goran (0.155m)
```

**用途**: 工場・倉庫・重機械設置部

### 🏠 屋根の軽量化戦略

#### roof1.csv - 軽量金属屋根
```
【外側】metal_plate (0.003m)
        ↓ 防水・耐久性
【内側】extruded_polystyrene (0.003m)
```

**設計意図**:
- **軽量性**: 構造負荷最小化
- **高耐久性**: 金属の長期耐候性
- **施工性**: シンプルな構成

## 建築工学的考察

### 🎯 設計思想の分類

#### 1. 伝統構法アプローチ
- **代表**: mud_wall.CSV
- **特徴**: 単一材料による多機能実現
- **利点**: 調湿性・蓄熱性・環境負荷軽減
- **課題**: 断熱性能の限界

#### 2. 現代構法アプローチ  
- **代表**: wall.CSV, wall1.csv
- **特徴**: 機能分離による最適化
- **利点**: 高性能・施工性・品質安定
- **課題**: 複雑性・コスト

#### 3. ハイブリッドアプローチ
- **代表**: wall5.csv
- **特徴**: 伝統技術＋現代技術の融合
- **利点**: 最高性能・多機能
- **課題**: 高コスト・施工複雑

### 🔄 材料組み合わせの原理

#### 断熱戦略
1. **連続断熱**: extruded_polystyrene による熱橋回避
2. **空気断熱**: vented_air_space による対流抑制
3. **複合断熱**: 材料＋空気層の組み合わせ

#### 調湿戦略
1. **透湿調湿**: ceramic_siding, paper による吸放湿
2. **通気調湿**: vented_air_space による湿気排出
3. **材料調湿**: mud_wall による自然調湿

#### 構造戦略
1. **主構造**: concrete_goran による力学的安全性
2. **軽量化**: plywood, metal_plate による重量軽減
3. **複合構造**: 異材料の適材適所配置

## 使用方法

### Juliaコードでの指定

```julia
# wall_condition.csv での指定例
num,IP,IM,Type,material_name
1,1,2,wall,wall.CSV        # 高性能外壁
2,2,3,ceiling1,ceiling1.csv # 標準天井  
3,2,4,floor1,floor1.csv     # 二重床
4,1,2,roof1,roof1.csv       # 金属屋根
```

### 新しい構成の作成

```csv
# 新構成例: high_performance_wall.csv
cell_number,material_name,thickness,temp,rh
1,ceramic_siding,0.020,20,60
2,extruded_polystyrene,0.100,20,60  
3,vented_air_space,0.050,20,60
4,concrete_goran,0.200,20,65
5,plasterboard,0.012,20,65
```

### 設計プロセス

1. **用途・性能目標の設定**
2. **既存構成からの選択 or 新規作成**
3. **熱湿気シミュレーションによる検証**
4. **最適化・調整**
5. **実施設計への反映**

## まとめ

### cell_dataの価値

✅ **実用性**: 実際の建築構法を正確にモデル化  
✅ **多様性**: 伝統構法から最新技術まで網羅  
✅ **検証性**: 異なる構成の性能比較が可能  
✅ **教育性**: 建築構法の理解に最適  
✅ **拡張性**: 新構成の追加が容易  

### 建築設計への貢献

1. **性能予測**: 設計段階での正確な性能評価
2. **最適化**: 用途・条件に応じた構成選択
3. **比較検討**: 複数案の定量的比較
4. **品質保証**: 設計意図の数値的検証

この包括的な壁体構成データベースにより、建築環境工学における構法設計の科学的アプローチが可能になり、高性能建築の実現に大きく貢献します。
