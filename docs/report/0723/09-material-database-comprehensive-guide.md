## データベース概要

### 収録材料数
**30種類**の建築材料を収録（`legacy-julia/module/material_property/`フォルダ）

### 対応物性値
- **基本物性**: 密度、比熱、熱伝導率、空隙率
- **水分特性**: 透湿率、含水率曲線、液水伝導率
- **特殊機能**: 結露判定、温度依存性、相変化

## 使用方法

### Juliaコードでの材料指定

```julia
# 材料名で直接指定
wall_material = "metal_plate"      # 金属外壁
insulation = "extruded_polystyrene" # 断熱材
interior = "plasterboard"          # 内装

# CSVファイルでの指定例
material_name,thickness,area
metal_plate,0.005,20.0
concrete_goran,0.15,4.0
glass_wool_16K,0.1,20.0
```

### 材料組み合わせの設計手順

1. **用途の明確化** - 外壁/内壁/屋根/床
2. **性能要求** - 断熱/調湿/防水/構造
3. **材料選定** - データベースから選択
4. **厚さ設定** - 性能計算による最適化
5. **境界条件** - 熱伝達率・湿気伝達率設定

### 新材料の追加方法

```julia
# 新材料ファイル例: new_material.jl
function property_new_material()
    # 基本物性
    rho = 1000.0          # 密度 [kg/m³]
    cp = 1000.0           # 比熱 [J/kg·K]
    psi = 0.3             # 空隙率 [-]
    
    # 熱伝導率 [W/m·K]
    lam = 0.5
    
    # 透湿率 [kg/m·Pa·s]
    ldmg = 1.0e-12
    
    # 含水率曲線
    function phi_curve(rh)
        return 0.1 * rh  # 線形例
    end
    
    return rho, cp, psi, lam, ldmg, phi_curve
end
```

## 技術仕様

### 含水率曲線の数学モデル

#### 1. 線形型（シンプル）
```julia
φ = a × RH + b
# 例：押出法ポリスチレン φ = 0.0018 × RH
```

#### 2. 有理関数型（多段階）
```julia
if RH < threshold
    φ = a × (b/(RH + c) + d)
else  
    φ = e × (f/(RH + g) + h)
end
# 例：セラミックサイディング（閾値RH=0.68）
```

#### 3. van Genuchten型（土壌科学）
```julia
φ = φr + (φs - φr) × (1 + (α×|h|)^n)^(-m)
# 例：ベンタイマー砂岩
```

#### 4. 複雑型（実測フィッティング）
```julia
# 4段階式（コンクリート）
if RH < 0.1015
    φ = complex_function_1(RH)
elseif RH < 0.5000  
    φ = complex_function_2(RH)
elseif RH < 0.9950
    φ = complex_function_3(RH)
else
    φ = complex_function_4(RH)
end
```

### 特殊機能

#### 結露判定機能（グラスウール16K）
```julia
if rh > 0.99  # 結露発生
    phi = 100.0  # 飽和状態
else
    phi = normal_curve(rh)
end
```

#### 温度依存性（土壌材料）
```julia
# 温度補正係数
temp_factor = exp(0.0673 × (temp - 273.15))
thermal_conductivity *= temp_factor
```

#### 湿度依存熱伝導率
```julia
# コンクリート
lambda = 1.3 + 3.5 × phi  # 強い湿度依存性

# 木質材
lambda = 0.113 + 3.14e-4 × phi × 1000  # 中程度依存性
```
