# 計算困難の原因分析とシンプル化戦略 - 2025/08/07

## 前回報告からの問題発生と対応

### 初期計算での困難に直面した経緯

前回の進捗報告（[01-wall-division-improvement-study.md](./01-wall-division-improvement-study.md)）では、4つの複雑なパターンで壁体分割数改善の検証を計画していました。しかし、実際の数値計算実行において重大な困難に直面し、戦略の見直しが必要となりました。

---

## 🚨 発生した計算困難の詳細分析

### 1. 物置小屋3室モデルでの計算エラー

#### エラー内容
```
DomainError with -4476.86034240745:
log was called with a negative real argument
```

#### エラー発生箇所
- **壁体3（屋根）**: 相対湿度が100%を超過（103-108%）
- **水蒸気圧計算**: 負の値により対数計算でエラー
- **計算停止**: 数時間の計算時間が無駄に

### 2. 複数パターンでの共通問題

| パターン | 分割数 | 屋根部分RH | 結果 | 問題要因 |
|---------|--------|------------|------|----------|
| storage | 6 | 103-108% | ❌ | 分割数の問題ではない |
| basic | 3 | 97-103% | ❌ | 材料厚さの問題ではない |
| insulated | - | 未実行 | - | 複雑すぎて検証不可 |
| high_performance | - | 未実行 | - | 複雑すぎて検証不可 |

### 3. 計算不安定性の根本原因

#### 物理設定の問題
1. **屋根材料**: 金属板の極薄設計（2-5mm）
2. **境界条件**: 水平屋根（ION=0°）の不適切な設定
3. **初期条件**: 温湿度バランスの不整合
4. **複雑性**: 3つの壁体×3つの部屋の相互作用

#### 工学的問題
1. **湿度制御**: 極端な湿度変動への対応困難
2. **相変化**: 結露・蒸発の境界条件処理
3. **収束性**: 非線形連立方程式の解の発散

## 🔄 シンプル化戦略の必要性

### 1. 研究目的の再確認

**元の目的**: 「壁が熱を伝えていない」問題の解決
**本質**: 分割数3→6の効果検証

**問題**: 複雑なモデルでは本質的効果が見えない
**解決**: モデルを極限まで単純化し、純粋に分割数効果のみを検証

### 2. 複雑性削減の段階的アプローチ

#### Step 1: 空間の簡略化
```
3室モデル → 2室モデル
外気 ↔ 物置 ↔ 地面  →  外気 ↔ 室内
```

#### Step 2: 壁体の簡略化
```
3つの壁体 → 1つの壁体
(外壁+床+屋根) → (外壁のみ)
```

#### Step 3: 材料の安定化
```
金属板(2mm) → コンクリート(200mm)
不安定材料 → 安定材料
```

#### Step 4: 境界条件の単純化
```
複雑な傾斜・方位 → 単純な垂直壁
多様な物性値 → 標準的設定
```

## 🏗️ 新シンプルモデルの設計思想

### 基本コンセプト
**「可能な限りシンプルに、しかし本質を失わずに」**

### 構成要素の最小化

#### 空間構成
- **外気室**: 外界気象（温度変動あり）
- **室内室**: 内部空間（初期温度25℃から応答）
- **接続**: 1つの壁のみで分離

#### 壁体仕様
- **材料**: コンクリート（安定した熱物性）
- **厚さ**: 0.2m（十分な熱容量）
- **面積**: 10m²（適度な熱交換面積）
- **分割**: 3分割 vs 6分割の比較

#### 境界条件
- **方位**: 南面垂直壁（標準的設定）
- **換気**: 最小限（0.005m³/s）
- **初期条件**: 現実的な温湿度設定

### 検証可能性の確保

#### 物理現象の明確化
1. **外気温変動** → **壁内温度勾配** → **室内温度応答**
2. **分割数効果** → **温度分布の精密度** → **熱伝導計算精度**

#### 定量比較の実現
- 同一条件でのdiv_num=3 vs 6の直接比較
- 壁体内温度分布の可視化
- 室内温度応答の差異定量化
