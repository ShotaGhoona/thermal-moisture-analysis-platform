### 1. room_condition（室条件）の比較

| 項目 | storage | simple | 差異 | 変更理由 |
|------|---------|---------|------|----------|
| **室数** | 3室 | **2室** | **1室削減** | **複雑性排除** |
| **室1（外気）** | outdoor, 1000m³, 20℃, 60%RH | **同じ** | **同じ** | 境界条件維持 |
| **室2（主室）** | storage_shed, 8.0m³, 20℃, 65%RH | **indoor, 20.0m³, 25℃, 50%RH** | **名称・容積・温湿度変更** | **現実的設定・安定化** |
| **室3（地面）** | ground, 10000m³, 15℃, 80%RH | **なし（削除）** | **完全削除** | **問題要素排除** |
| **高さ設定** | 0, 2.5, 0m | **0, 3.0m** | 主室高さ変更 | より現実的な室高 |

#### 🔍 主要変更点の詳細分析

**室2（主室）の変更**:
```
storage: storage_shed, 8.0m³, 20℃, 65%RH, 2.5m高
    ↓ 【4つの変更】
simple:  indoor, 20.0m³, 25℃, 50%RH, 3.0m高
```

**変更理由**:
1. **容積拡大** (8.0→20.0m³): より現実的な居住空間
2. **温度差設定** (20→25℃): 外気との明確な温度差で熱伝導検証
3. **湿度低下** (65→50%RH): 湿度異常リスク回避
4. **室高増加** (2.5→3.0m): 標準的な居住空間高

**室3（地面）の削除理由**:
- 複雑な3室相互作用の排除
- 問題の単純化・本質抽出
- 地面の高湿度(80%RH)による湿度異常リスク排除

| **開口数** | 1つ | **1つ** | **同じ** | **基本構造維持** |

| **接続室** | 1(outdoor)↔2(storage) | **1(outdoor)↔2(indoor)** | **同じ接続関係** | **構造維持** |

#### 🔍 換気条件変更の意図

**換気量削減の効果**:
```
storage: 0.01m³/s  → 強めの換気
simple:  0.005m³/s → 微小換気（半分）
```

**変更理由**:
1. **外乱最小化**: 換気による温湿度変動を最小化
2. **熱伝導強調**: 壁体を通じた熱伝導を相対的に重要にする
3. **計算安定化**: 強すぎる換気による不安定性回避

## 💡 変更戦略の工学的意図

### 1. 複雑性削減アプローチ

#### 空間の簡略化
```
storage: 外気 ↔ 物置 ↔ 地面（3室の複雑な相互作用）
         ↓
simple:  外気 ↔ 室内（2室のシンプルな関係）
```

#### 壁体の簡略化
```
storage: 3つの壁体（外壁・床・屋根の相互作用）
         ↓
simple:  1つの壁体（外壁のみの単純系）
```

### 2. 安定性確保アプローチ

#### 材料の安定化
```
storage: 金属板（高熱伝導・急激応答・湿度異常リスク）
         ↓

```

#### 初期条件の最適化
```
storage: 同温度スタート（20℃均一）
         ↓
simple:  温度差スタート（外気20℃・室内25℃）
```

### 3. 検証精度向上アプローチ

#### 分割数効果の純粋化
```
storage: 3つの壁体すべてがdiv_num=6（複合的効果）
         ↓
simple:  1つの壁体のみdiv_num=3 vs 6（純粋効果）
```

#### 測定指標の明確化
```
storage: 複雑な室間温度関係
         ↓
simple:  外気→壁→室内の単純な熱伝導
```

## 🔍 「なぜ変えたのか」の核心理由

### 計算エラーからの学習

**storage系での失敗**:
1. **湿度異常**: 屋根部分で103-108%RHの異常値
2. **計算停止**: DomainErrorによる強制終了
3. **原因不明**: 複雑すぎて問題の特定困難

**simple系での解決策**:
1. **問題要素排除**: 屋根（湿度異常源）の完全削除
2. **安定材料採用**: 金属→コンクリートで急激変動回避
3. **条件統制**: 分割数以外の変数を極力固定

### 研究目的への回帰

**元の目的**: 「壁が熱を伝えていない」問題の解決
**storage系**: 複雑すぎて本質が見えない
**simple系**: 分割数効果の純粋検証が可能

### 段階的研究戦略

```
Phase 1: simple系で基本効果確認 ← 現在
         ↓
Phase 2: 段階的複雑化
         ↓  
Phase 3: storage系への応用
```
