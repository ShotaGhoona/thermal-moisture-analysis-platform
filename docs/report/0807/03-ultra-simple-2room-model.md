# 極シンプル2室モデル - 分割数効果検証版 - 2025/08/07

## 2025年7月版からの重要な変更点

### 🔄 モデル簡略化の経緯
前回の物置小屋3室モデル（0723版）では計算が不安定で湿度異常によりエラーが発生。**「壁が熱を伝えていない」問題の純粋検証**のため、極限まで単純化した2室モデルに再設計。

### 📊 主要な変更点の比較

| 項目 | 2025/07/23版 | 2025/08/07版 | 変更理由 |
|------|-------------|-------------|----------|
| **室数** | 3室（外気・物置・地面） | **2室（外気・室内）** | 計算安定性確保 |
| **壁体数** | 3つ（外壁・床・屋根） | **1つ（外壁のみ）** | 問題の単純化 |
| **材料** | 金属板（2-5mm） | **コンクリート（200mm）** | 安定した物理特性 |
| **分割数** | 1（分割なし） | **3 vs 6で比較** | 分割数効果の検証 |
| **容積** | 物置8m³ | **室内20m³** | より現実的な空間 |
| **目的** | 日常的建物の解析 | **数値計算手法の検証** | 学術的焦点の明確化 |

## CSVファイル設定

### room_condition_simple.csv（共通）
```csv
num,name,vol,temp,rh,Hight,Qs,Js,AC
1,outdoor,1000,20,60,0,0,0,OFF
2,indoor,20,25,50,3.0,0,0,OFF
```

**空間定義の変更**:
- **outdoor**: 外気（1000m³）※変更なし
- **indoor**: 室内（**20m³**）← storage_shed（8m³）から拡大
- **ground**: **削除** ← 複雑性排除

### wall_condition_simple_div3.csv（分割数3版）
```csv
num,IP,IM,Type,div_num,material_name,temp,rh,thickness,area,ION,dir_IP,dir_IM,alphac_IP,alphac_IM,aldm_IP,aldm_IM
1,1,2,0,3,concrete_goran,22,55,0.2,10,90,S,N,19,9,3.2e-8,3.2e-8
```

### wall_condition_simple_div6.csv（分割数6版）
```csv
num,IP,IM,Type,div_num,material_name,temp,rh,thickness,area,ION,dir_IP,dir_IM,alphac_IP,alphac_IM,aldm_IP,aldm_IM
1,1,2,0,6,concrete_goran,22,55,0.2,10,90,S,N,19,9,3.2e-8,3.2e-8
```

**壁体定義の大幅変更**:
- **材料**: metal_plate → **concrete_goran**（安定性重視）
- **厚さ**: 0.003-0.005m → **0.2m**（十分な熱容量）
- **分割数**: 1 → **3 vs 6**（検証対象）
- **面積**: 4-20m² → **10m²**（標準的設定）
- **壁数**: 3つ → **1つ**（極限簡略化）

### opening_condition_simple.csv（共通）
```csv
BC,IP,IM,Type,Qup,Qdw,A
1,1,2,constant,0.005,0.005,2.0
```

**換気設定の変更**:
- **換気量**: 0.05m³/s → **0.005m³/s**（1/10に削減）
- **タイプ**: opening → **constant**（一定換気量）

## 検証目標の明確化

### 1. 計算安定性の確認
- **0723版**: 湿度異常でエラー停止
- **0807版**: 18ヶ月間の安定計算

### 2. 分割数効果の定量化
- **分割数3**: 壁体を3つのセルで計算
- **分割数6**: 壁体を6つのセルで計算
- **比較項目**: 壁内温度分布、室内温度応答、熱流束

### 3. 「壁が熱を伝えていない」問題の解決
- **問題**: 外気温変動が室内に伝わらない
- **仮説**: 分割数不足による計算精度不足
- **検証**: div3 vs div6での明確な差異確認
