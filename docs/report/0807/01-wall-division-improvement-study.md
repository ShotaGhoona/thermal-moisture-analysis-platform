# 壁体分割数改善による熱伝導精度向上研究 - 2025/08/07

## 研究概要

前回の物置小屋熱水分解析実験において「壁が熱を伝えていない」という重要な指摘を受け、壁体分割数と構造設計が熱伝導計算精度に与える影響を定量的に検証する研究を実施中。

---

## 🚨 問題意識

### 1. 前回実験での課題
- **現象**: シミュレーション結果で壁体を通じた熱伝導が適切に表現されていない
- **原因仮説**: 壁体の分割数不足（div_num=3）により、壁体内部の温度勾配が十分に計算されていない可能性
- **影響**: 建物全体の熱収支計算の精度低下、実際の物理現象との乖離

### 2. 建築環境工学的重要性
- **学術的意義**: 壁体熱伝導は建築環境制御の基本現象
- **実用的意義**: 断熱設計、省エネルギー計算の基礎
- **検証の必要性**: 数値計算手法の妥当性確認

---

## 🔬 研究仮説

### 主仮説
**「壁体分割数を増加させることで、壁体内部の温度勾配がより精密に計算され、熱伝導現象が適切に表現される」**

### 検証すべき要素

#### 1. 分割数の影響
- **仮説1**: 分割数3→6により、壁体内温度分布の計算精度が向上
- **仮説2**: 分割数の増加により、外気温変動に対する室内温度の応答性が改善
- **仮説3**: 適切な分割数により、壁体の蓄熱・放熱効果が正確に反映

#### 2. 構造設計の影響
- **仮説4**: 単層構造（Type=0）と複層構造（cell_data使用）で熱伝導特性が異なる
- **仮説5**: 断熱材の追加により、温度勾配がより明確に表現される
- **仮説6**: 材料の組み合わせ（金属+断熱材+内装材）により、各層の熱的役割が可視化される

## 🧪 実験設計

### 実験パターン（4種類）

#### パターン1: storage（改善版）
```
構造: 単層構造・分割数6
材料: 金属板(0.005m) + コンクリート床(0.15m)
目的: 前回指摘の直接的改善効果検証
```

#### パターン2: storage_insulated
```
構造: 複層構造・断熱材入り
材料: 金属板 + グラスウール + 石膏ボード
目的: 標準的な断熱壁の熱伝導特性確認
```

#### パターン3: storage_high_performance
```
構造: 複層構造・高性能断熱
材料: 金属板 + 通気層 + 厚い断熱材 + 内装材
目的: 高断熱建築での熱伝導挙動解析
```

#### パターン4: storage_basic
```
構造: 単層構造・分割数3
材料: 薄い材料構成
目的: ベースライン比較用
```

### 比較検証項目

#### 1. 熱伝導精度
- 壁体内温度勾配の可視化
- 外気温変動に対する室内温度応答性
- 熱流束の時間変化

#### 2. 物理現象の再現性
- 日射の影響による壁面温度上昇
- 夜間放射による冷却効果
- 壁体蓄熱による温度位相遅れ

#### 3. 数値計算の安定性
- 計算収束性
- エネルギー収支の保存性
- 計算時間の比較
