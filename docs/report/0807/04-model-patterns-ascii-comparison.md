## 🔥 計算エラーの原因分析

### 湿度異常パターンの共通点

#### storage & basic vs original_0723 の比較
```
【original_0723 - 成功パターン】
壁体3（屋根）: div_num=1
┌─────────────────────────────────┐
│ 外気(RH60%) → 金属屋根 → 室内   │
│                ↓              │
│         【安定計算領域】        │
│       RH = 60-80% ✅          │
│                ↓              │
│     正常計算 → 成功・問題発見   │
└─────────────────────────────────┘

【storage & basic - エラーパターン】  
壁体3（屋根）: div_num=3/6
┌─────────────────────────────────┐
│ 外気(RH60%) → 金属屋根 → 室内   │
│                ↓              │
│         【問題発生箇所】        │
│       RH = 103-108% ❌         │
│                ↓              │
│    log(-4476) → DomainError    │
└─────────────────────────────────┘
```

#### 原因要素の特定
1. **分割数増加の逆効果**: div_num=1→3/6で湿度異常が発生
2. **極薄金属材料**: 2-5mmの薄さで急激な温湿度変化
3. **水平屋根設定**: ION=0°で雨水滞留しやすい条件  
4. **複雑な境界条件**: 3つの壁体間の相互作用
5. **初期条件不整合**: 温湿度バランスの不適切な設定

**重要な発見**: original_0723では正常だったものが、分割数を増やすことで異常になった

### simple モデルの成功要因

#### 安定化要素の分析
```
┌─────────────────────────────────┐
│ 外気(RH60%) → コンクリート壁 → 室内 │
│                ↓              │
│         【安定計算領域】        │
│       RH = 50-60% ✅          │
│                ↓              │
│    正常な水蒸気圧計算 → 成功    │
└─────────────────────────────────┘
```

#### 成功要素の特定
1. **安定材料**: 200mmコンクリートで緩やかな応答
2. **垂直壁**: ION=90°で標準的な境界条件
3. **単純構造**: 1つの壁体で相互作用排除
4. **現実的初期条件**: バランスの取れた温湿度設定

## 🎯 分割数効果検証の戦略

### simple モデルでの pure 検証

#### 分割数3 パターン
```
外気 → [セル1|セル2|セル3] → 室内
        ↑    ↑    ↑
    温度T1  温度T2  温度T3
    
壁体内温度勾配: 粗い分解能
計算精度: 標準
計算時間: 短
```

#### 分割数6 パターン  
```
外気 → [セル1|セル2|セル3|セル4|セル5|セル6] → 室内
        ↑    ↑    ↑    ↑    ↑    ↑
       T1   T2   T3   T4   T5   T6
       
壁体内温度勾配: 細かい分解能  
計算精度: 高精度
計算時間: 長
```

#### 検証項目
1. **温度勾配**: 6分割で より滑らかな温度分布
