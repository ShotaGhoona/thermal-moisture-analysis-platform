### 換気量と計算タイプの関係

#### Type: opening vs constant の違い

**opening型（original_0723_div6）**:
```
Type=opening, Qup=0.05, Qdw=0.05
→ 開口部の物理的特性を考慮した計算
→ 圧力差・風速・開口形状の影響あり
→ より現実的な換気計算
```

**constant型（storage系・simple）**:
```  
Type=constant, Qup=0.01, Qdw=0.01
→ 一定換気量での固定計算
→ 外部条件に関係なく一定
→ 計算安定性重視
```

## 🎯 「なぜこの設定にしたのか」の分析

### 換気量設定の戦略的意図

#### simple: 0.005m³/s（最小限）
**理由**:
1. **外乱最小化**: 換気による温湿度変動を最小化
2. **壁体重視**: 壁を通じた熱伝導を相対的に重要にする  
3. **計算安定化**: 強すぎる換気による不安定性回避
4. **分割数効果強調**: 換気が弱いほど壁体分割数の差が顕著に

#### storage系: 0.01m³/s（中程度）
**理由**:
1. **現実的バランス**: 実際の物置小屋の換気レベル
2. **計算安定性**: constant型で安定した計算
3. **比較基準**: 他パターンとの中間的位置づけ

#### original_0723_div6: 0.05m³/s（大きめ）
**理由**:
1. **オリジナル準拠**: 0723年7月版との整合性維持
2. **opening型**: より現実的な開口計算手法
3. **基準維持**: 分割数以外の条件は元のまま

### 開口面積設定の意図

| パターン | 面積(m²) | 設定意図 |
|---------|----------|----------|

## 🔬 計算への影響予測

### 換気量による室内環境への影響

#### 強換気（0.05m³/s）
```
効果: 外気温湿度に素早く追従
特徴: 外気変動 → 室内変動（強い相関）
壁体効果: 相対的に小さく見える
分割数効果: 換気が支配的で差が見えにくい
```

#### 中換気（0.01m³/s）
```  
効果: 外気と壁体のバランス
特徴: 外気変動 ↔ 壁体蓄熱のバランス
壁体効果: 適度に現れる
分割数効果: 中程度に見える
```

#### 微換気（0.005m³/s）
```
効果: 壁体伝熱が支配的
特徴: 壁体蓄熱 → 室内変動（壁体支配）
壁体効果: 明確に現れる  
分割数効果: 最も顕著に見える
```

## 🎯 結論

### 重要な発見
1. **storage系は内部で完全同一** - 壁体構成に関係なく開口条件は変わらない
2. **simple系の戦略的設計** - 換気影響を最小化し壁体効果を最大化
3. **original_0723_div6の基準準拠** - 分割数以外は元仕様維持

### 工学的意義
各パターンの開口条件設定により、**「換気 vs 壁体伝熱」のバランス**を戦略的に制御し、分割数効果の見え方を調整している。

**simple系**の微換気設定が、分割数効果の純粋検証に最も適していることが確認できた。
