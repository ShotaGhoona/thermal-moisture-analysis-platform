# FFT解析結果ファイル説明

## 概要

このディレクトリには、`concrete_high`パターン（コンクリート壁+強換気 0.5 m³/s）の室内温度データに対するFFT解析とハーモニック回帰分析の結果が格納されています。

## 分析対象データ

- **建物タイプ**: コンクリート壁 + 強換気（0.5 m³/s）
- **解析データ**: room2（室内）温度
- **期間**: 約122日間（2022年4月1日～）
- **サンプリング間隔**: 10分（600秒）
- **データ点数**: 17,568点（NaN除去後）

## 出力ファイル一覧

### 1. `harmonic_analysis_results_fft_concrete_high.csv`
**基本FFT解析結果**

| 列名 | 内容 | 単位 |
|------|------|------|
| Frequency (Hz) | 周波数 | Hz |
| Period (Day) | 周期 | 日 |
| Amplitude | 振幅 | °C |
| Phase (radians) | 位相 | ラジアン |

- **データ数**: 8,785行（全周波数成分）
- **DC成分**: 22.08°C（平均温度）
- **主要周期**: 122日（振幅2.62°C）、61日（0.91°C）、1日（2.92°C）







### 2. `harmonic_analysis_results_fft_concrete_high_waveforms.csv`
**時系列波形データ**

| 列名 | 内容 | 単位 |
|------|------|------|
| Time [s] | 時間 | 秒 |
| Time [day] | 時間 | 日 |
| Original | 元データ | °C |
| Reconstructed | FFT再構成波形 | °C |

- **用途**: 元データとFFT逆変換による再構成波形の比較
- **精度**: R² ≈ 1.0（完全再構成）






### 3. `harmonic_analysis_results_concrete_high_fourier_spectrum.csv`
**詳細周波数スペクトル**

基本FFT結果と同内容だが、ハーモニック回帰分析用に整理されたバージョン。

### 4. `harmonic_analysis_results_concrete_high_harmonic_components.csv`
**各周波数成分の時系列波形**

| 列名 | 内容 |
|------|------|
| Time [s] | 時間（秒） |
| Original Data | 元の温度データ |
| inf Day_component | DC成分（平均値） |
| 122.0 Day_component | 122日周期成分 |
| 1.0 Day_component | 1日周期成分 |
| その他 | 各周期成分の個別波形 |

- **成分数**: 51個の主要周波数成分
- **用途**: 各周期成分の寄与度分析、成分分離





### 5. `harmonic_analysis_results_concrete_high_harmonic_coefficients.csv`
**ハーモニック回帰係数**

| 列名 | 内容 |
|------|------|
| Component | 周期成分名 |
| cos_coeff | コサイン係数 |
| sin_coeff | サイン係数 |
| Amplitude | 計算された振幅 |
| Phase (radians) | 計算された位相 |

- **用途**: 最小二乗法による回帰分析結果
- **応用**: 予測モデル構築、成分分析

## 主要な分析結果

### 温度特性
- **平均温度**: 22.08°C
- **温度範囲**: 5.38°C ～ 36.97°C
- **変動幅**: 31.59°C

### 主要周期成分
1. **DC成分**: 22.08°C（平均値）
2. **122日周期**: 振幅2.62°C（季節変動）
3. **61日周期**: 振幅0.91°C（半季節変動）
4. **1日周期**: 振幅2.92°C（日変動、強換気の影響で顕著）
5. **30.5日周期**: 振幅0.97°C（月変動）

### concrete_highパターンの特徴
- **外気追従性**: 高（強換気の効果）
- **日変動**: 明確（1日周期振幅2.92°C）
- **季節応答**: 顕著（122日周期振幅2.62°C）
- **換気効果**: 外気温度変化への迅速な応答

## データの活用方法

### 1. 建物性能評価
- 外気追従性の定量評価
- 換気効果の検証
- エネルギー負荷予測

### 2. 比較分析
- 他パターン（concrete_low, wood_low, wood_high）との比較
- 材料特性vs換気量の効果分離

### 3. 予測モデル
- ハーモニック回帰係数を用いた温度予測
- 季節・日内変動の予測精度向上

## 注意事項

- データにはNaN値が含まれていたため、1,161点を除去済み
- 周波数0（DC成分）は特別処理（期間無限大）
- 位相は-π～+πの範囲で表現
- 強換気による外気依存特性が顕著に現れている
