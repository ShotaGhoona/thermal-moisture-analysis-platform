# 研究目的と解析手法解説

## 🎯 **今回の研究で何をしようとしているのか**

### 大きな目標
**「建物の温度データを見ただけで、その建物がどんな材料で作られ、どんな換気をしているかを当てる技術を作る」**

### 具体的な研究内容
1. **4つの建物パターンの「指紋」を作る**
   - `concrete_low`: コンクリート + 微換気（0.005 m³/s）
   - `concrete_high`: コンクリート + 強換気（0.5 m³/s）
   - `wood_low`: 木材 + 微換気
   - `wood_high`: 木材 + 強換気

2. **温度の「波形パターン」から建物を診断**
   - 「この波形なら、コンクリート+強換気の建物だ！」
   - 「この周期性なら、木材+微換気の建物だ！」

3. **実用的な建物診断システムの開発**
   - 不動産の性能評価
   - 省エネ改修の効果予測
   - 建築設計の最適化

## 🌊 **フーリエ変換とは何か**

### 簡単な例え
**「音楽を楽器ごとに分解する技術」**

```
混合された音楽 → フーリエ変換 → ピアノの音 + バイオリンの音 + ドラムの音
複雑な温度変化 → フーリエ変換 → 1日周期 + 1週間周期 + 1年周期
```

### 建築での応用
```
室内温度の複雑な変化
↓ フーリエ変換
├── DC成分（平均温度）: 22.08°C
├── 1日周期（日変動）: 振幅2.92°C
├── 122日周期（季節変動）: 振幅2.62°C
├── 61日周期（半季節）: 振幅0.91°C
└── その他の周期成分...
```

### なぜフーリエ変換が有効か
1. **隠れた周期性の発見**
   - 人間の目では見えない微細な周期変動を検出
   - 外気の影響、建物の蓄熱効果、換気の影響を分離

2. **定量的な比較**
   - 「なんとなく変動が大きい」→「1日周期が2.92°C」
   - 数値化により客観的な建物比較が可能

3. **物理現象との対応**
   - 1日周期 → 太陽の影響、外気温変動
   - 季節周期 → 年間の気候変化
   - 短周期 → 換気、人の活動

## 📈 **ハーモニック回帰分析とは何か**

### 簡単な説明
**「重要な周期だけを使って、元の温度変化を数式で表現する技術」**

### 数学的な表現
```python
温度(t) = 平均温度 + A₁×cos(2π×t/T₁) + B₁×sin(2π×t/T₁) + 
                    A₂×cos(2π×t/T₂) + B₂×sin(2π×t/T₂) + ...

ここで：
- T₁, T₂, ... は主要な周期（1日、122日など）
- A₁, B₁, A₂, B₂, ... は各周期の強さ（回帰係数）
```

### 具体例（concrete_highの場合）
```
室内温度 = 22.08°C（平均）
         + 2.62°C × cos(2π×t/122日 + 位相)  ← 季節変動
         + 2.92°C × cos(2π×t/1日 + 位相)    ← 日変動
         + 0.91°C × cos(2π×t/61日 + 位相)   ← 半季節変動
         + ...
```

### ハーモニック回帰の利点
1. **予測可能**
   - 数式があるので未来の温度を予測できる
   - 「明日の同じ時刻は何度になるか」

2. **成分の重要度がわかる**
   - 季節変動: 2.62°C（大きい）
   - 日変動: 2.92°C（最も大きい）← 強換気の証拠

3. **建物特性の数値化**
   - 係数の組み合わせが建物の「指紋」になる

## 🏗️ **建築工学での意義**

### 1. **材料効果の分離**
```
コンクリート（高蓄熱）→ 長周期の変動が緩やか
木材（低蓄熱）     → 短周期の変動が敏感
```

### 2. **換気効果の定量化**
```
微換気（0.005 m³/s）→ 1日周期が小さい（室内が独立）
強換気（0.5 m³/s） → 1日周期が大きい（外気追従）
```

### 3. **省エネ性能の評価**
```
変動が小さい → 安定した室内環境 → 冷暖房負荷が小さい
変動が大きい → 不安定な環境  → 冷暖房負荷が大きい
```

## 🔬 **研究の革新性**

### 従来の建物診断
- **視覚的判断**: 「なんとなく暑い/寒い」
- **単発測定**: 一時点の温度測定
- **経験依存**: 専門家の勘に頼る

### 今回の手法
- **数値的診断**: 「1日周期2.92°C、122日周期2.62°C」
- **連続解析**: 長期間の時系列データ活用
- **客観的評価**: 数学的手法による再現可能な診断

## 🎯 **concrete_highパターンで分かったこと**

### 発見事実
1. **強換気の効果**
   - 1日周期が2.92°C（大きい）→ 外気の影響を直接受ける
   - 平均温度22.08°C → 外気温に近い

2. **コンクリートの特性**
   - 122日の長周期変動 → 蓄熱効果は残存
   - 位相遅れ → 外気変化から室内変化まで時間差

3. **建物の「個性」**
   - この周期パターン = concrete_high建物の「指紋」
   - 他パターンと明確に区別可能

### 実用的価値
- **省エネ評価**: 変動幅から冷暖房負荷を予測
- **快適性評価**: 急激な温度変化の有無を定量化  
- **建物診断**: 測定データから建物仕様を逆算推定

---

**結論**: この研究は、建築物の「DNA解析」のようなもので、温度データという「遺伝子情報」から建物の「体質」（材料・換気特性）を科学的に解明する革新的手法です。
