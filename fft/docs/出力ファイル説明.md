# FFT解析 出力ファイル説明

## 出力ファイル一覧

### 1. `harmonic_analysis_results_fft_indoor_measurement_temp.xlsx`
**FFT（高速フーリエ変換）の結果**

#### シート構成：
- **Fourier Spectrum シート**
  - `Frequency (Hz)`: 周波数（ヘルツ）
  - `Period (Day)`: 周期（日単位）
  - `Amplitude`: 振幅
  - `Phase (radians)`: 位相（ラジアン）

- **Waveforms シート**
  - `Time [s]`: 時間（秒）
  - `Time [day]`: 時間（日）
  - `Original`: 元の測定データ
  - `Reconstructed`: 逆フーリエ変換による再構成波形

### 2. `harmonic_analysis_results_indoor_measurement_temp.xlsx`
**ハーモニック回帰分析の結果**

#### シート構成：
- **Fourier Spectrum シート**
  - 全周波数成分のスペクトル情報
  - `Frequency (Hz)`: 周波数
  - `Amplitude`: 振幅
  - `Phase (radians)`: 位相

- **Harmonic Components シート**
  - 各周波数成分の時系列波形
  - `Time [s]`: 時間（秒）
  - `Original Data`: 元データ
  - `[周期]_component`: 各周期成分の波形（例：`121.7 Day_component`）

- **Harmonic Coefficients シート**
  - 回帰分析の係数と統計情報
  - `Component`: 周波数成分の名称
  - `cos_coeff`: コサイン係数
  - `sin_coeff`: サイン係数
  - `Amplitude`: 計算された振幅
  - `Phase (radians)`: 計算された位相

### 3. `~$` で始まるファイル
**一時ファイル（Excelの作業ファイル）**
- Excelでファイルを開いている際に自動生成される一時ファイル
- 通常は非表示で、Excelを閉じると自動削除される
- 解析には影響しないため無視して構わない

## ファイルの使い分け

### FFT結果ファイル（`*_fft_*.xlsx`）
- **用途**: 基本的な周波数解析
- **特徴**: 全周波数成分の情報を含む
- **適用**: スペクトル分析、周期性の確認

### ハーモニック回帰結果ファイル（`harmonic_analysis_*.xlsx`）
- **用途**: 主要周波数成分の詳細分析
- **特徴**: 上位51成分の個別波形と回帰係数
- **適用**: 主要周期の寄与度分析、成分分離

## 分析の流れ

1. **FFT解析** → 全体的な周波数特性の把握
2. **主要成分抽出** → 振幅の大きい上位51成分を特定
3. **ハーモニック回帰** → 各成分の詳細な特性分析
4. **結果出力** → 両方のExcelファイルに保存
