# FFT解析ノートブック概要と使い方

## 概要

このノートブック（`fft/analyze_by_FFT.ipynb`）は、時系列データに対してフーリエ変換とハーモニック回帰分析を行うツールです。主に温度データの周期性解析に使用されます。

## 主な機能

### 1. フーリエ変換（FFT）
- 時系列データの周波数成分を解析
- 振幅スペクトルと位相スペクトルの計算
- 逆フーリエ変換による波形の再構成

### 2. ハーモニック回帰
- 主要な周波数成分を抽出（上位51成分）
- 最小二乗法による回帰分析
- 各周波数成分の個別波形の生成

## 使い方

### 必要なライブラリのインストール
```bash
pip install EMD-signal
pip install xlsxwriter
```

### 入力データの準備
- 入力ファイル：`input_data/input_data_indoor_measurement.xlsx`
- データ形式：時系列の温度データ（Excel形式、ヘッダー行2行目）

### 実行手順
1. ライブラリの読み込み
2. データの読み込みと前処理
3. フーリエ変換の実行
4. ハーモニック回帰の実行
5. 結果の可視化と出力

### 出力ファイル
- **FFT結果**：`output_data/harmonic_analysis_results_fft_indoor_measurement_temp.xlsx`
  - Fourier Spectrum シート：周波数、周期、振幅、位相
  - Waveforms シート：元データと再構成波形の時系列
  
- **ハーモニック回帰結果**：`output_data/harmonic_analysis_results_indoor_measurement_temp.xlsx`
  - Fourier Spectrum シート：全周波数のスペクトル
  - Harmonic Components シート：各周波数成分の波形
  - Harmonic Coefficients シート：回帰係数と振幅・位相

## 分析のポイント

- **サンプリング間隔**：データの時間間隔から自動計算
- **主要周波数の抽出**：振幅の大きい上位51成分を分析
- **周期の表示**：日単位での周期表示（例：1日、2日、121.7日など）
- **可視化**：元データ、再構成波形、各周波数成分のグラフ表示

## 適用例

室内温度測定データの解析において、以下の周期性を検出：
- 長期トレンド（121.7日周期）
- 中期変動（20-60日周期）
- 短期変動（数日～十数日周期）
