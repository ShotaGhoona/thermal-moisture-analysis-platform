# 研究概要とタイトル案

## 📝 **研究概要（500文字）**

建物の室内外温度測定データから建物性能（壁材料・換気量等）を逆算推定する機械学習手法を開発する。従来、建物性能から温度は予測可能だが、逆に温度データから建物仕様を特定することは理論的に困難とされてきた。本研究では、測定データに含まれる建物情報を機械学習により抽出することを目指す。まず、材料（コンクリート・木材）と換気量（微換気・強換気）を変数とした4パターンの建物をシミュレーションし、学習用データセットを構築する。次に、複雑な温度時系列データをFFT（高速フーリエ変換）により周波数成分に分解し、建物特性を反映する特徴量を抽出する。外気変動に対する室内応答の周期特性（日変動・季節変動等）を定量化し、各建物パターンの「指紋」を作成する。最終的に、温度データの周波数特徴から建物性能を推定するモデルを構築し、既存建物の性能診断や省エネ改修効果予測への応用を図る。この手法により、簡易な温度測定のみで建物の客観的性能評価が可能となる。

## 💡 **発表時のポイント**

### **研究の独自性**
1. **逆問題へのチャレンジ**: 温度→建物性能（従来は建物性能→温度）
2. **周波数解析の新応用**: FFTを建築診断に活用
3. **理論限界の機械学習突破**: 数式では解けない問題をAIで解決

### **社会的意義**
1. **既存建物の性能評価**: 膨大なストック建築の客観的評価
2. **省エネ改修**: 効果的な改修計画立案支援
3. **建築設計**: データ駆動型設計手法の確立

1. **シミュレーションデータ**: julia計算による高精度学習データ
2. **特徴量エンジニアリング**: FFT→周波数特徴→機械学習
3. **検証可能性**: 4パターン×複数条件での系統的検証
